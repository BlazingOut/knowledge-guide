# 计算机网络

目标：面向 AI 应用开发岗秋招，建立"一次网络请求从发出到返回"的完整心智模型，覆盖计算机网络面试高频考点。本课程属于基础知识部分，只讲清知识本身，示例使用通用、贴近真实工程的场景（浏览器访问网站、调用 LLM API、日常排错等），不与具体项目强行关联。

本课程共十二课，原则是**理论先行、实践在后**：第 1 至第 4 课把传输层的核心理论学完（分层、IP、TCP/UDP、握手挥手），第 5 课才进入 socket 编程，第 7 至第 10 课完成 DNS 和 HTTP 系列理论，第 11 课把观察排错命令汇总成工具箱，第 12 课综合复盘。后续课程用到工具类命令时只做一句话说明并引用第 11 课。HTTP/2、HTTP/3 和 WebSocket 并入第 10 课，不单独开课。

## 前置知识

会用终端运行命令，理解进程和端口的基本含义；会用 Python 编写和运行简单脚本，了解函数、异常和 `bytes` 类型。

## 课程结构

### 第 1 课：网络分层模型与协议栈

目标：建立 OSI 七层模型与 TCP/IP 四层模型的心智模型，理解"协议"和"分层封装"的含义，能够回答"为什么分层"这一高频面试题。

内容：每一层的职责、典型协议和设备（链路层、网络层、传输层、应用层）；数据封装与解封装的过程；各层协议的对应关系；分层带来的好处和代价。

实践：用 Python 模拟一次 HTTP 请求的逐层封装和解封装（不使用 socket），观察"发送端自上而下加头、接收端自下而上剥头"的完整过程。

面试考点：OSI 与 TCP/IP 模型的区别；一次请求经过哪些层；为什么业务代码不需要关心 TCP 细节。

### 第 2 课：IP 地址、子网与路由基础

目标：理解 IPv4 地址、子网掩码、私有地址和 NAT，能够解释"本机如何和公网服务器通信"。

内容：IPv4 地址结构和点分十进制；子网掩码与 CIDR（如 `192.168.1.0/24`）；私有地址段、回环地址 `127.0.0.1` 和 `0.0.0.0` 的含义；NAT 的作用；路由和默认网关的基本概念；IPv6 与 IPv4 的主要差异。

实践：用 `ifconfig`/`ip addr` 查看本机地址与掩码，用 `ping` 感受回环、局域网和公网的差异（命令详解在第 11 课）；用子网划分练习题巩固计算。

面试考点：为什么本地服务有时用 `127.0.0.1` 访问不到；私有地址为什么能上网（NAT）；子网划分计算。

### 第 3 课：UDP、TCP 与端口

目标：理解传输层的职责，区分 TCP 和 UDP 的报文结构与适用场景。

内容：端口的作用和常见端口（80、443、22、8000）；UDP 报文结构和无连接特性；TCP 报文中的序号、确认号和标志位（本课只介绍字段，握手挥手在第 5 课展开）；TCP 与 UDP 的对比和各自典型应用（大模型流式接口、DNS、视频通话）。

实践：用 `lsof` 观察本机进程监听的端口（命令详解在第 11 课）；对照报文结构图（SVG）辨认 UDP 和 TCP 报文的字段。

面试考点：TCP 和 UDP 的区别及各自场景；端口是什么、为什么需要；一个端口能被多个进程占用吗。

### 第 4 课：TCP 三次握手与四次挥手

目标：掌握 TCP 建立连接和断开连接的完整过程，能够回答面试中所有握手挥手相关的高频追问。本课是第 5 课 socket 编程的理论前提。

内容：三次握手的每一步报文、状态变化（SYN_SENT、ESTABLISHED 等）和原因（为什么不能是两次）；四次挥手的过程和 TIME_WAIT、CLOSE_WAIT 状态；半连接队列与 SYN 洪泛攻击；`keep-alive` 与 HTTP `Keep-Alive` 的区别。

实践：用 `ss -tan` 观察 ESTABLISHED、TIME_WAIT 状态（命令详解在第 11 课），解释 `listen()` 之后客户端 `connect()` 即可成功的原因（握手由操作系统内核完成，`accept()` 只是取走已建立的连接）；故意不关闭 socket，观察服务端出现的 CLOSE_WAIT。

面试考点：为什么三次握手不是两次；TIME_WAIT 为什么等待 2MSL；大量 TIME_WAIT 或 CLOSE_WAIT 说明什么；服务端出现大量 CLOSE_WAIT 如何排查。

### 第 5 课：socket 编程

目标：掌握 socket 这一传输层编程接口：它是什么、操作系统替你做了什么、如何用它编写 UDP 和 TCP 的客户端与服务器。本课需要第 4 课的握手知识作前提，也是后续粘包、HTTP 各课实践的基础，必须详细展开。

内容：socket 的概念（操作系统提供的编程接口，位于应用层与传输层之间）；socket 对象的生命周期（创建、连接/绑定、收发、关闭）；UDP socket：`sendto`/`recvfrom` 的输入输出和适用场景；TCP socket：`connect`、`send`/`recv`、`bind`/`listen`/`accept` 三步各做了什么、为什么 accept 返回新的 socket；阻塞行为的含义；字节流传输的注意事项（`recv` 的缓冲区参数、返回空字节表示连接关闭）；常见异常（`ConnectionRefusedError`、`ConnectionResetError`）及产生原因。

实践：编写完整的 UDP 收发程序和 TCP 客户端/服务器程序；一次连接中多次收发消息；故意连接不存在的端口，观察异常。

面试考点：socket 是什么、和 TCP 的关系；accept 为什么返回新 socket；`recv` 返回空字节意味着什么。

### 第 6 课：TCP 可靠传输：确认、重传、流量控制与拥塞控制

目标：理解 TCP 如何在不可靠网络上实现可靠、有序、不淹没对方的数据传输。

内容：确认应答与超时重传；滑动窗口与流水线传输；流量控制（接收窗口）；拥塞控制四个阶段（慢启动、拥塞避免、快重传、快恢复）；粘包与拆包问题，以及为什么应用层需要自己定义消息边界（对 JSON/流式响应的意义）。

实践：用 Python 向 `socket` 发送两条紧挨着的消息，观察接收端一次读到"粘"在一起的数据，再实现简单的分隔符协议解决它；结合大模型 API 的流式返回讨论流式响应的边界。

面试考点：TCP 如何保证可靠；滑动窗口的作用；拥塞控制和流量控制的区别；TCP 粘包的原因和解决方法。

### 第 7 课：DNS 域名解析

目标：理解"从域名到 IP"的完整过程，能够回答 DNS 解析顺序和递归迭代查询的高频题。

内容：域名结构和层级；本地缓存、hosts 文件、本地 DNS 服务器、根域名服务器、顶级域名服务器、权威域名服务器；递归查询与迭代查询；常见记录类型（A、AAAA、CNAME、NS）；DNS 用 UDP 53 端口的原因。

实践：用 `dig`/`nslookup` 解析一个常见 API 域名（命令详解在第 11 课），观察 CNAME 链和 TTL；查看 hosts 文件验证解析顺序。

面试考点：浏览器输入 URL 后发生了什么（本课讲 DNS 部分，为第 9 课铺垫）；递归与迭代查询的区别；为什么 DNS 常用 UDP。

### 第 8 课：HTTP 基础：报文、方法与状态码

目标：掌握 HTTP 请求和响应的完整格式，能读懂并手写一次 HTTP 报文。

内容：请求行、请求头、请求体和响应行、响应头、响应体；常见方法（GET、POST、PUT、DELETE、PATCH）和幂等性；常见状态码分类（200、301/302、400、401/403、404、500、502/504）；常见请求头和响应头（`Content-Type`、`Authorization`、`Content-Length`、`Connection`）；短连接与长连接（HTTP/1.1 默认 `Keep-Alive`）。

实践：用 `curl -v` 观察完整报文（命令详解在第 11 课）；用 Python `socket` 手写一个最小的 HTTP 请求（不使用任何 HTTP 库），再用 `http.server` 手写一个最小的 HTTP 服务器返回 JSON；对照第 1 课的分层模型，说明框架和操作系统替我们做了什么。

面试考点：GET 和 POST 的区别；常见状态码含义，502 和 504 的区别；什么是幂等；HTTP 报文的结构。

### 第 9 课：HTTPS、TLS 与会话保持

目标：理解 HTTPS 的加密和证书验证流程，掌握 Cookie、Session、Token 三种会话方式的区别。

内容：对称加密与非对称加密；TLS 握手过程（证书验证、密钥交换、对称加密通信）；数字证书、CA 和签名的作用；为什么混合加密；Cookie 的属性（`HttpOnly`、`Secure`、`SameSite`）；Session 与 JWT Token 的对比；Web 服务如何通过 `Authorization` 头和 Cookie 携带身份。

实践：用 `curl -v https://…` 观察 TLS 握手过程；用 Python `requests` 演示携带 Cookie 和携带 Bearer Token 两种调用方式。

面试考点：HTTPS 握手过程；对称与非对称加密为什么混合使用；什么是中间人攻击、证书如何防伪造；Cookie、Session、Token（JWT）的区别和各自场景。

### 第 10 课：HTTP/2、HTTP/3 与代理网关

目标：了解现代 Web 协议的演进方向，理解代理、负载均衡和网关在工程中的角色。

内容：HTTP/1.1 的队头阻塞问题；HTTP/2 的多路复用、头部压缩和服务端推送；HTTP/3 与 QUIC（基于 UDP）；WebSocket 的握手升级和全双工通信；正向代理与反向代理的区别；负载均衡的基本策略；网关和限流；调用 LLM API 时代理、超时和重试的真实工程问题。

实践：用 `requests` 配置代理访问接口；观察 HTTP 流式响应与 WebSocket 的区别；用 `curl` 比较 HTTP/1.1 与 HTTP/2（如可用）的连接行为。

面试考点：HTTP/1.1、HTTP/2、HTTP/3 的区别；什么是队头阻塞；WebSocket 和 HTTP 的关系；正向代理和反向代理的区别；为什么调用大模型 API 需要处理超时和流式。

### 第 11 课：网络观察与排错命令工具箱

目标：系统掌握观察和排查网络问题的常用终端命令，形成"逐层定位"的排错习惯。此时分层、握手、DNS、HTTP 等理论已经学完，正是把零散用过的命令整理成体系的时候。本课之后再用到这些命令，一律一句话带过并引用本课。

内容：命令按用途分类讲解——观察本机配置（`ifconfig`/`ip addr`、`netstat -rn`/`ip route`）；观察连接与端口（`lsof` 和 `ss` 的参数逐个详解、两者对比）；测试连通性（`ping` 的工作原理：ICMP、TTL、往返时间、丢包率）；追踪路径（`traceroute` 与逐跳转发）；发起请求（`curl` 的常用参数，报文细节已在第 8 课学过）；解析域名（`dig` 的输出结构，机制已在第 7 课学过）。每个命令都说明"它看什么、正常输出长什么样、什么输出说明有问题"。

实践：综合运用上述命令对本机网络做一次"体检"，并对人为制造的问题（服务没启动、端口占用、ping 不通的地址）给出定位结论。

面试考点：排查"接口连不上/超时"时会按什么顺序用什么命令；`lsof` 和 `ss` 的区别；`ping` 通但端口连不上说明什么。

### 第 12 课：综合复盘：URL 到 LLM 回答

目标：把全部知识点串成一次完整的请求链路，并通过面试问答练习检验掌握程度。

内容：完整复盘"浏览器输入 URL → DNS → TCP 握手 → TLS 握手 → HTTP 请求 → 反向代理 → 后端服务 → 调用上游 LLM API（又是完整链路）→ 流式返回"的每一步；梳理各层可能的故障和排查手段；整理本课程面试高频题清单并模拟回答。

实践：用 Python 编写一个最小程序，同时充当"服务器"（接收请求）和"客户端"（转发调用另一个服务），模拟后端服务转发调用 LLM API 的真实结构；人为制造几类故障（端口占用、错误地址、错误路径），练习用第 11 课的命令逐层排查。

面试考点：经典综合题"输入 URL 之后发生了什么"的完整版回答；如何排查一个线上接口超时；各层协议的故障分别是什么现象。

## 综合练习

完成"最小 API 转发服务"：用 Python 标准库实现一个同时监听请求、解析 HTTP 报文、向上游发起 HTTPS 请求并把结果返回的迷你服务，过程中亲手处理端口绑定、消息边界、超时和错误状态码。

## 阶段验收

学习者应能够：

1. 画出分层模型，并说明一次 HTTP 请求在每一层发生了什么。
2. 解释 IP 地址、端口、子网、NAT，以及本地服务和公网服务的地址差别。
3. 说清 TCP 三次握手、四次挥手的过程、状态和常见追问。
4. 用 socket 编写简单的 UDP 和 TCP 程序，解释 socket 的生命周期和阻塞行为。
5. 解释 TCP 可靠传输机制和粘包问题的成因与解决。
6. 描述 DNS 解析的完整顺序，区分递归与迭代。
7. 手写 HTTP 请求和响应报文，解释常见方法、状态码和头部。
8. 说清 HTTPS 握手、证书验证，以及 Cookie、Session、JWT 的区别。
9. 解释代理、负载均衡、网关的概念，并联系 LLM API 调用的工程实践。
10. 熟练使用 ifconfig、ping、lsof/ss、netstat -rn、traceroute、curl 等命令观察网络状态，并对常见故障给出定位结论。
11. 用自己的话完整回答"从输入 URL 到收到大模型回答经历了什么"。

## 课程编写约束

- **理论先行、实践在后**：先用文档讲清概念和机制，动手编程的课安排在对应理论之后；工具类命令集中在一课详解，其余课程一句话带过并引用。
- 讲解要有逻辑、够详细：每个引入的工具、模块或 API 都要说明它是什么、解决什么问题、输入输出和副作用；重要的工具值得单独成课，不要一笔带过。
- 每课只引入少量新概念，先运行观察，再讲解原理；同一知识点不在多课重复展开。
- 在必要的地方使用 SVG 示意图辅助讲解（如分层模型、握手流程、报文结构），放在本目录 `assets/` 下，以 `![说明](./assets/xxx.svg)` 引用；示意图沿用本仓库已有风格，避免整课全靠文字描述。
- 每课明确标注"面试高频考点"，但讲解从机制讲起，不直接给背诵结论。
- 实践优先使用 Python 标准库（`socket`、`http.server`、`http.client`、`ssl`），需要第三方库（如 `requests`）时先说明安装方式和它封装了什么。
- 每课使用通用、贴近真实工程的示例（浏览器访问网站、调用外部 API、日常排错等），不与 Life Manager 项目强行关联。
- 每课的实践代码与课后作业放在同一个 Python 文件中，遵循课程编写要求第 4 节的结构。本课程采用选择性配代码：第 1、5、6、8、12 课编写标准代码文件（课程示例 + 同文件作业）；第 2、3、4、7、9、10、11 课以课程文档为主，配终端演示命令和验收问题，不编写代码作业。
- 网络实验只针对本机或学习者自己启动的课程进程，不对局域网其他设备发起扫描或请求。
