# Docker 课程

本课程建立"应用如何被打包、运行和编排"的基础心智模型，服务于 Redis、FastAPI 和后续部署学习。Docker 能帮助你理解"应用、依赖和运行环境如何被打包"，也是本地开发和团队协作中常见的工具。

前置要求：已完成 Redis 课程第一课（已经通过 `docker run` 启动过 Redis 容器），或已完成本课程第一课。

## 课程目标

完成本课程后，你应当能够：

- 用自己的话解释 Docker 是什么、容器是怎么隔离的；
- 在自己的电脑上安装并验证 Docker；
- 证明容器是隔离的，并会用换 tag、换容器、换端口的方式切换环境；
- 完成镜像和容器的日常管理（查看、拉取、停止、删除、日志、进入容器）；
- 用 Dockerfile 构建自己的镜像；
- 理解端口映射、数据卷、环境变量和容器网络；
- 用 Docker Compose 编排多服务环境；
- 把 FastAPI、Redis 和数据库放进一套本地开发环境。

## 课时目录

1. [Docker 机制与原理](./01-Docker机制与原理.md) — Docker 是什么（集装箱类比）、三个视角看容器、隔离机制、镜像与容器、容器与虚拟机。
2. [Docker 安装与验证](./02-Docker安装与验证.md) — 系统要求、启用 WSL2、安装 Docker Desktop、AMD64/ARM64 选择、验证 hello-world 和 Redis 容器。
3. [环境隔离与切换](./03-环境隔离与切换.md) — 容器网络机制、端口映射原理（门 A/门 B、总机转分机）、两个容器看隔离、三面墙隔离原理、换 tag/换容器/换端口切换环境。
4. [镜像与容器的日常管理](./04-镜像与容器的日常管理.md) — 镜像查看与拉取、镜像 tag、镜像来源与可信判断（Docker Hub）、容器生命周期、日志、进入容器、安全清理。
5. 用 Dockerfile 构建自己的镜像 — Dockerfile 基本指令、构建与缓存、`.dockerignore`。
6. 端口映射与数据卷 — 端口映射原理、卷挂载与数据持久化。
7. 环境变量与容器网络 — 环境变量传递、容器间通信。
8. Docker Compose — 多服务编排、常用命令。
9. 综合练习：把课程项目装进 Docker — FastAPI + Redis + 数据库的本地开发环境。

第 5 课及以后：待编写。

## 学习方式

第一课只讲机制，不安装软件；从第二课开始动手执行。命令示例中 `#` 后面的文字是注释，实际执行时不输入。

练习容器统一使用课程命名（如 `redis-course`）。练习结束后删除自己的练习容器和不再使用的镜像；删除前先确认容器用途，不要随意删除共享环境或不确定的容器。
