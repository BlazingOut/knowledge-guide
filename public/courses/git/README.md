# 阶段 0：Git 与开发工作流

本阶段不重复讲解 Conda、包安装和项目目录。重点是建立一套能够解释 Git 行为、审查代码变化、保护已有修改并支持并行工作的心智模型。

## 课程目标

完成本阶段后，你应当能够：

- 区分工作区、暂存区、当前提交和 Git 对象库。
- 解释 `HEAD`、分支、远程分支和提交之间的关系。
- 使用 `git status`、`git diff`、`git diff --staged`、`git log`、`git show` 审查变化。
- 使用 `git restore` 安全地撤销工作区或暂存区中的修改。
- 使用分支、合并和冲突标记完成一次可解释的合并。
- 理解 `git reset`、`git revert`、`git stash` 的适用范围和风险。
- 使用 `git worktree` 在多个目录中同时检出不同分支。
- 在本项目中建立提交前检查和实验隔离习惯。

实践代码和实验仓库位于 [`code/git/`](../../../code/git/)。课程中的实验会创建临时提交和分支，不会修改正式项目；开始前请确认当前路径是课程实验目录。

## 学习方式

每一课先阅读“状态变化”，再执行命令。不要只记住命令的效果，要在执行前预测 `status`、`diff` 或 `log` 会显示什么，然后用实际结果校正自己的理解。

本阶段的安全规则是：不在正式项目上进行重置、强制切换、删除分支或清理 worktree 实验；不使用 `git reset --hard`；任何撤销操作前先查看 `git status` 和相关 diff。
