# 操作系统

目标：面向 AI 应用开发岗秋招，建立"一个程序在计算机上如何真正运行"的完整心智模型，覆盖操作系统面试高频考点（进程线程、IPC、锁与死锁、调度、虚拟内存、页面置换、文件系统、IO 模型等）。本课程属于基础知识部分，只讲清知识本身，示例使用通用、贴近真实工程的场景（多进程下载任务、并发服务、日志排查等），不与 Life Manager 项目强行关联。

本课程共十一课，原则是**理论先行、实践在后**：第 1 至第 5 课把"CPU 上的程序"讲完（操作系统总览、进程线程、IPC、同步锁、调度），第 6 至第 7 课完成内存管理，第 8 课文件系统，第 9 课把 IO 模型和多路复用讲透（依赖第 2 至第 4 课的进程线程与同步知识），第 10 课把观察排错命令汇总成工具箱，第 11 课综合复盘。后续课程用到工具类命令时只做一句话说明并引用第 10 课。进程与 Linux 命令的基础部分（如 `ps` 的最基本用法）已在 Linux 课程出现，本课程不做重复入门讲解，而是在第 10 课从"操作系统机制"的角度把命令讲深。

## 前置知识

会用终端运行命令，对"进程、端口、文件"有直观认识；会用 Python 编写和运行简单脚本，了解函数、异常、类和多线程的基本写法（不要求熟练）。

## 课程结构

### 第 1 课：操作系统的四个子系统

目标：建立操作系统的心智模型——它是管理硬件资源、向上提供服务的软件；理解进程管理、内存管理、文件系统、IO 管理四大子系统的分工，能回答"操作系统为应用程序做了什么"。

内容：内核与用户态的分工；系统调用的概念（应用程序进入内核的唯一入口）；四大子系统各自管理什么资源、互相如何配合；以"双击打开一个程序"为例串起：fork/exec 创建进程、分配虚拟内存、读文件、写屏幕；宏内核与微内核的一句话区分。

实践：用 `strace`（macOS 用 `dtrace`/`truss`，命令详解在第 10 课）观察 `python -c 'print(1)'` 触发的系统调用，直观看到"你以为的一行代码，底下是几十次系统调用"。

面试考点：操作系统是什么、内核态与用户态的区别；系统调用、库函数、应用程序三者的关系；为什么不能让应用直接操作硬件。

### 第 2 课：进程与线程

目标：分清进程、线程、协程三个层次，理解进程的组成与线程共享的资源，这是整个课程和并发面试题的地基。本课必须详细展开。

内容：进程是什么（运行中程序 + 资源分配的基本单位）；进程控制块（PCB，进程描述符）记录了什么；进程地址空间的五段布局（代码、数据、堆、栈、环境参数）；进程状态机（五状态模型：新建、就绪、运行、阻塞、终止，附 SVG 状态图）；fork/exec 的语义与写时复制（Copy-on-Write）；线程是什么（CPU 调度的基本单位）、用户级线程与内核级线程；线程共享什么（地址空间、堆、全局变量）、独享什么（栈、寄存器、程序计数器）；协程是什么、与线程的差别；进程 vs 线程 vs 协程的对比表。

实践：用 Python `multiprocessing` 和 `threading` 各写一个最小计数程序，观察"多进程各自计数互不影响、多线程共享变量互相干扰"的现象（干扰现象为第 4 课埋伏笔）；用 `ps -ef`/`top` 观察进程与线程（命令详解在第 10 课）。

面试考点：进程和线程的区别及各自场景；一个进程崩了为什么通常不影响别的进程；线程崩溃会怎样；协程解决什么问题；多核 CPU 上多线程一定更快吗。

### 第 3 课：进程间通信（IPC）

目标：理解"为什么进程之间不能直接传数据"，掌握各类 IPC 机制的原理和适用场景。

内容：为什么需要 IPC（地址空间隔离这一设计选择带来的必然结果）；管道（匿名管道与命名管道 FIFO）；消息队列；共享内存（为什么它最快：数据零拷贝，但要配合同步原语）；信号量（P/V 操作，本课只讲计数语义，锁在第 4 课展开）；信号（signal：异步通知机制，`SIGKILL`、`SIGTERM`、`SIGINT` 的区别）；socket 作为 IPC 的特殊地位（唯一可跨主机）；各类机制的速度、限制、典型场景对比表。

实践：用 Python `os.pipe`、`multiprocessing.Queue`、`multiprocessing.Value` 分别实现父子进程传数据，感受"复制传值"与"共享传值"的差别；用 `kill -9` 和 `Ctrl+C`（SIGINT）终止进程，观察信号的效果（命令详解在第 10 课）。

面试考点：常见 IPC 方式及优缺点；管道和消息队列的区别；共享内存为什么快、为什么还需要信号量；`kill -9` 和 `kill -15` 的区别、能不能被捕获。

### 第 4 课：线程同步：竞态、锁与死锁

目标：理解并发正确性问题的根源，掌握互斥锁、信号量、条件变量三大同步原语，能完整回答死锁相关的高频追问。本课必须详细展开，是并发类面试的核心。

内容：竞态条件（race condition）的根源：多线程交错执行读-改-写；临界区与互斥的要求；互斥锁（mutex：加锁、解锁、自旋锁与互斥锁的等待方式差别）；信号量用于同步次序；条件变量与等待/唤醒；生产者-消费者模型（完整推导为什么要条件变量而不是忙等待）；可重入与死锁：死锁四个必要条件（互斥、持有并等待、不可剥夺、循环等待）逐一解释并给出对应破坏策略；活锁与饥饿一句话区分；锁的粒度与常见工程陷阱（忘记释放、锁内调用慢操作）。

实践：用 Python 复现第 2 课的计数干扰现象，用 `threading.Lock` 修复它；用两个线程按相反顺序加两把锁复现死锁，再用"固定加锁顺序"修复；实现生产者-消费者队列。

面试考点：什么是竞态条件、举一个例子；自旋锁和互斥锁的区别及场景；死锁的四个必要条件和避免方法；生产者-消费者怎么实现；乐观锁和悲观锁的概念。

### 第 5 课：CPU 调度

目标：理解操作系统如何在多个就绪进程间分配 CPU，掌握主要调度算法的思想与权衡。

内容：为什么需要调度（CPU 数量远小于任务数量）；上下文切换的完整过程（保存寄存器、切换页表、切换内核栈，为什么切换有代价）；抢占式与非抢占式；经典算法逐个讲：FCFS、SJF（最短作业优先）、时间片轮转（RR，时间片大小的权衡）、优先级调度与饥饿问题、多级反馈队列（综合前几种，重点讲）；实时调度一句话引入（SRTF/EDF 不展开）；多核调度与缓存亲和性一句话引入。

实践：用 Python 模拟 FCFS、RR、SJF 三种算法处理同一批"任务"，输出各自的平均周转时间对比表格（纯内存模拟，不涉及真实并发）。

面试考点：进程调度的时机；时间片太大太小各有什么问题；什么是饥饿、优先级反转；多级反馈队列为什么好；上下文切换保存了什么。

### 第 6 课：内存管理：虚拟内存与分页

目标：理解虚拟内存这一操作系统的核心抽象，掌握地址翻译的机制，能回答"为什么每个进程都有 4G/128T 地址空间"。

内容：没有虚拟内存时的问题（地址冲突、进程互相破坏、内存碎片）；虚拟地址空间与物理内存的分离；MMU（内存管理单元）与页表：虚拟页号到物理页号的翻译过程（附 SVG 地址翻译图）；多级页表（为什么需要：单级页表太大）；TLB（快表）与局部性原理；物理内存分配与内部碎片/外部碎片；交换空间（swap）的角色；Linux 中进程地址空间的实际布局（代码段、数据段、堆、mmap 区、栈，与第 2 课五段模型呼应）。

实践：用 `vmmap`/`pmap` 观察一个 Python 进程的地址空间分段（命令详解在第 10 课）；用 Python 申请大块内存前后对比 `top` 中的内存指标，理解"申请了不等于立刻占用物理内存"。

面试考点：虚拟内存是什么、解决什么问题；页表的作用、多级页表为什么省内存；TLB 是什么；逻辑地址到物理地址的完整翻译过程；malloc 之后内存就真的分配了吗。

### 第 7 课：缺页中断、页面置换与内存问题

目标：掌握虚拟内存按需加载的机制，理解常见页面置换算法，能识别和解释内存不足的工程现象。

内容：缺页中断（page fault）的完整处理流程；请求分页与工作集；置换算法逐个讲：FIFO（含 Belady 异常）、OPT（最优，仅作基准）、LRU（及其硬件实现代价）、Clock（时钟/第二次机会，工程中真实使用的近似 LRU）；抖动（thrashing）的成因与现象；OOM（Out of Memory，内存耗尽） Killer 的工作方式；内存泄漏 vs 内存溢出的区别；Go/Java/Python 语言层面的 GC 与操作系统的内存回收是什么关系（一句话澄清，不展开语言 GC）。

实践：用 Python `functools.lru_cache` 对比不同缓存容量下的命中率，直观感受 LRU 思想；模拟页面引用序列，用代码实现 FIFO 与 LRU 并统计缺页次数（本课代码作业之一）。

面试考点：缺页中断的处理流程；FIFO、LRU、Clock 算法的过程；Belady 异常是什么；什么是抖动；进程被 OOM Kill 如何排查。

### 第 8 课：文件系统

目标：理解文件在磁盘上如何被组织和管理，掌握 inode 机制和软硬链接的区别。

内容：文件与目录的抽象；块设备与扇区/块；inode（索引节点）机制：inode 存什么、目录项存什么（文件名到 inode 号的映射，附 SVG 结构图）；为什么目录也是文件；软链接（symbolic link）与硬链接（hard link）的机制差别和限制；文件的打开过程（路径解析 → inode → 文件描述符）；文件描述符（fd）与第 9 课 IO 的衔接；日志文件系统（journaling）一句话引入（崩溃一致性）；虚拟文件系统 VFS（为什么同一套代码能读写不同文件系统）。

实践：用 `stat`、`ls -i`、`ln`/`ln -s` 创建硬链接和软链接，观察 inode 号变化与删除源文件后的差别（命令详解在第 10 课）；用 Python `os.open`/`os.read` 与内建 `open` 对照，看清文件描述符这一层。

面试考点：inode 是什么、存了哪些信息；硬链接和软链接的区别；删除文件后空间立即释放吗（文件被占用的情况）；文件描述符是什么、`ulimit -n` 限制的是什么。

### 第 9 课：IO 与并发模型：从阻塞到 epoll

目标：把"一个进程怎么同时服务成千上万个连接"讲透。本课是 IO 类面试题的总纲，依赖第 2、4 课的线程与同步知识，必须详细展开。

内容：用户态与内核态的 IO 边界；缓冲区与 read/write 的真实含义；五种 IO 模型逐一讲：阻塞 IO、非阻塞 IO、IO 多路复用、信号驱动（一句话）、异步 IO；`select` 的机制与限制（fd 数量、每次全量拷贝与遍历）；`poll` 的改进；`epoll` 的机制（红黑树注册、就绪链表、事件回调，为什么比 select 快，附 SVG 对比图）；水平触发（LT）与边缘触发（ET）；Reactor 模型与"单进程 Reactor + 工作线程池"的典型结构；零拷贝（`sendfile`、`mmap`：数据为什么能不经过用户态）；进程池/线程池的价值。

实践：先用多线程版 echo 服务器（第 2 课知识），再用 Python `selectors` 模块（封装 epoll/kqueue）实现单线程并发 echo 服务器，对比两者处理大量连接时的行为差异；用 `time` 对比大文件复制中普通读写与 `mmap` 的差别（选做）。

面试考点：五种 IO 模型的区别；select/poll/epoll 的区别及各自限制；epoll 为什么高效；LT 和 ET 的区别；什么是零拷贝、普通 read+write 一共拷贝几次；单线程单进程为什么能撑高并发。

### 第 10 课：进程与系统观察命令工具箱

目标：系统掌握观察进程、内存、文件、IO 的常用终端命令，形成"从现象到机制"的排错习惯。此时各子系统机制已学完，正是把命令按机制归类讲深的时候。本课之后再用到这些命令，一律一句话带过并引用本课。Linux 课程已教过的命令只做"机制视角"的加深，不重复入门用法。

内容：按子系统分类讲解——进程观察与控制（`ps` 的常用参数、`top`/`htop` 各字段含义：VIRT/RES/SHR 的区别、`kill` 与信号、`nice`）；内存观察（`free` 的 buff/cache、`vmstat`）；文件与磁盘（`df` 与 `du` 为什么不一致、`lsof`：从 fd 角度重新认识它）；系统调用追踪（`strace` 的常用参数）；上下文切换与负载（`uptime` 的 load average 到底是什么、`pidstat`）。每个命令都说明"它看的是哪个子系统、正常输出长什么样、什么输出说明有问题"。

实践：综合运用上述命令对本机做一次"体检"，并对人为制造的问题（写死循环吃满一个核、逐步吃内存、打开大量 fd）给出定位结论。

面试考点：load average 多少算高、和 CPU 使用率的区别；VIRT 和 RES 的区别；`free` 里内存只剩很少是否正常（buff/cache）；排查"服务卡死"会按什么顺序用什么命令。

### 第 11 课：综合复盘：从启动一个服务到内存耗尽

目标：把全部知识点串成"程序的一生"，并通过面试问答练习检验掌握程度。

内容：完整复盘"执行 `python server.py` 之后发生了什么"：shell fork/exec → 加载 ELF、建立虚拟地址空间 → 缺页逐步载入代码和数据 → 线程创建 → 监听端口、epoll 事件循环 → 每个请求经过的系统调用 → 日志落盘经过的内核路径；梳理各子系统的典型故障和排查手段（CPU 高、内存高、fd 泄漏、IO 慢分别看什么）；整理本课程面试高频题清单并模拟回答。

实践：编写一个小型并发服务（epoll 事件循环 + 线程池处理），人为制造四类故障（死锁、内存泄漏、fd 泄漏、CPU 空转），用第 10 课命令逐一定位。本课代码作业之一。

面试考点：经典综合题"程序运行慢/挂了怎么排查"的完整版回答；"从敲下命令到进程运行发生了什么"；各子系统故障分别是什么现象。

## 综合练习

完成"可诊断的并发服务"：用 Python 标准库实现一个 epoll 驱动、线程池工作的小服务，并配套编写四个故障开关（死锁、泄漏、fd 耗尽、空转），学习者需要能打开任一开关后用第 10 课的命令定位到根因。

## 阶段验收

学习者应能够：

1. 解释操作系统的四大子系统分工，说清系统调用、内核态与用户态的关系。
2. 说清进程、线程、协程的区别，画出进程五状态图，解释 fork 和写时复制。
3. 列出常见 IPC 方式并比较优缺点，解释共享内存为什么快。
4. 用锁、信号量、条件变量解决典型并发问题，完整回答死锁四条件。
5. 解释主要调度算法的权衡和上下文切换的代价。
6. 描述虚拟地址到物理地址的翻译过程，解释多级页表和 TLB 的作用。
7. 手算 FIFO/LRU 的缺页次数，解释抖动和 OOM Killer。
8. 解释 inode 机制，区分硬链接与软链接，说明文件描述符是什么。
9. 说清五种 IO 模型、select/poll/epoll 的演进原因和零拷贝的原理。
10. 熟练使用 ps/top/kill/free/df/du/lsof/strace/uptime 等命令，从现象定位到子系统的根因。
11. 用自己的话完整回答"执行 python server.py 之后操作系统发生了什么"。

## 课程编写约束

- **理论先行、实践在后**：先用文档讲清概念和机制，动手编程的课安排在对应理论之后；工具类命令集中在一课详解，其余课程一句话带过并引用。
- 讲解要有逻辑、够详细：每个引入的机制、结构或系统调用都要说明它是什么、解决什么问题、输入输出和副作用；重要的机制（如 epoll、虚拟内存、锁）值得整课展开，不要一笔带过。
- 每课只引入少量新概念，先运行观察，再讲解原理；同一知识点不在多课重复展开。
- 在必要的地方使用 SVG 示意图辅助讲解（如进程状态机、地址翻译、inode 结构、select/epoll 对比），放在本目录 `assets/` 下，以 `![说明](./assets/xxx.svg)` 引用；示意图沿用本仓库已有风格，避免整课全靠文字描述。
- 每课明确标注"面试高频考点"，但讲解从机制讲起，不直接给背诵结论。
- 实践优先使用 Python 标准库（`os`、`sys`、`threading`、`multiprocessing`、`selectors`、`functools`、`resource`），需要第三方库时先说明安装方式和它封装了什么。
- 每课使用通用、贴近真实工程的示例（并发服务、任务下载、日志排查等），不与 Life Manager 项目强行关联。
- 本课程采用选择性配代码：第 2、3、4、5、7、9、11 课编写标准代码文件（课程示例 + 同文件作业，代码放 `code/os/`）；第 1、6、8、10 课以课程文档为主，配终端演示命令和验收问题，不编写代码作业。
- 所有实验只针对本机或学习者自己启动的课程进程，不做任何对其他主机或网络的探测。
