# Redis 与缓存

目标：理解 Redis 在 Web 服务和 AI 应用中的常见职责，能够实现缓存、计数、限流、幂等和基础异步任务，为后续单独学习分布式后端打好基础。

本课程共十三课。前八课学习 Redis 基础、原理和缓存，后五课学习并发控制与异步任务。CAP、Redis 集群运维、完整微服务治理等分布式系统内容不放在本课程中，后续单独开课。

## 前置知识

完成 Python、FastAPI 和数据库基础课程，能够：

- 使用 Python 函数、异常、类型标注和基本模块；
- 启动 FastAPI 服务并理解请求、响应和依赖注入；
- 使用 SQL 完成查询、事务和参数化操作；
- 解释数据库、缓存和 API 的基本职责。

## 课程结构

### 第 1 课：Redis 基础与连接

目标：理解 Redis Server、客户端和 Python Redis 客户端，能够完成基本连接、读写和排错。

内容：Redis 与 SQLite/MySQL 的区别；内存数据服务；`redis-cli`；`PING`、`SET`、`GET`、`DEL`；连接地址、端口、逻辑数据库和持久化的基本认识。

实践：启动本地 Redis，分别使用命令行和 Python 完成写入、读取、删除和连通性检查。

材料：`./01-Redis基础与连接.md`。

### 第 2 课：Redis 常见数据结构

目标：根据数据访问方式选择 String、Hash、List、Set 和 Sorted Set。

内容：String 保存整体值；Hash 保存对象字段；List 保存有序元素；Set 去重和成员判断；Sorted Set 排行和按分数排序；Redis 数据结构与关系型表的区别。

实践：使用 Hash 保存用户状态，使用 Set 保存标签，使用 Sorted Set 实现排行榜，使用 List 保存简单任务。

材料：`./02-Redis常见数据结构.md`。

### 第 3 课：Redis 原理：为什么快与底层结构

目标：能分层回答"Redis 为什么快"，理解主要数据结构的底层实现关键词。

内容：内存存储；SDS；单线程命令执行与 IO 多路复用（epoll）；List 的 quicklist 与 listpack；Set 的 intset 与哈希表；Sorted Set 的跳表与哈希表；渐进式 rehash；`OBJECT ENCODING`。

实践：用 `OBJECT ENCODING` 观察不同值和规模的 Key 的底层编码变化。

材料：`./03-Redis原理：为什么快与底层结构.md`。

### 第 4 课：持久化与内存淘汰

目标：理解 RDB、AOF 和混合持久化的区别与选择，理解过期删除和内存淘汰策略。

内容：RDB 快照与触发；AOF 追加、fsync 策略与重写；混合持久化；惰性删除与定期删除；maxmemory 与 LRU/LFU 淘汰策略；持久化与数据库职责边界。

实践：用 `CONFIG GET` 查看当前持久化和淘汰配置，观察过期 Key 的删除行为。

材料：`./04-持久化与内存淘汰.md`。

### 第 5 课：Key 设计、过期时间与连接池

目标：设计清晰的 Redis Key，设置数据生命周期，并理解客户端连接池。

内容：业务前缀、对象编号、用途和环境；`EXPIRE`、`TTL`、`SET EX`、`PERSIST`；永久 Key 与临时 Key；连接复用、连接池和基础超时。

实践：为用户会话、文章缓存和限流计数器设计 Key，并观察不同 TTL 的变化。

材料：`./05-Key设计、过期时间与连接池.md`。

### 第 6 课：Cache Aside 缓存模式

目标：为查询接口实现缓存命中、缓存未命中、数据库回源和缓存回填。

内容：先查缓存；未命中查询数据库；使用过期时间回填；更新数据库后删除缓存；数据库和 Redis 的职责边界；缓存不可用时的基本降级。

实践：为一个 SQLite 查询接口增加 Redis 缓存，观察第一次读取和后续读取的差异。

材料：`./06-Cache Aside缓存模式.md`。

### 第 7 课：缓存问题与基础防护

目标：识别缓存穿透、缓存击穿、缓存雪崩、热点 Key 和大 Key。

内容：不存在数据导致的缓存穿透；热点 Key 失效导致的缓存击穿；大量 Key 同时失效导致的缓存雪崩；空值缓存、随机 TTL、热点保护和服务降级。

实践：为不存在的资源增加短期空值缓存，为正常数据设置随机过期时间，并观察回源次数。

材料：`./07-缓存问题与基础防护.md`。

### 第 8 课：缓存与数据库一致性

目标：理解数据库和缓存的更新顺序、删除失败和最终一致性。

内容：更新数据库后删除缓存；先删除缓存再更新数据库的风险；直接更新缓存；延迟双删；删除失败后的重试和补偿；缓存不能替代数据库事务。

实践：模拟数据库更新成功但缓存删除失败，记录不一致状态并设计恢复方式。

材料：`./08-缓存与数据库一致性.md`。

### 第 9 课：计数器、原子操作与限流

目标：使用 Redis 的原子操作实现计数和固定窗口限流。

内容：`INCR`、`DECR`、`INCRBY`；Python 读改写的并发问题；计数器 TTL；按用户、IP 和接口生成限流 Key；固定窗口边界问题；单条命令与多条命令的原子性差异。

实践：为 FastAPI 接口增加按用户的固定窗口限流，超过限制时返回 429。

材料：`./09-计数器、原子操作与限流.md`。

### 第 10 课：幂等键与重复请求

目标：使用唯一请求号避免网络重试导致重复创建或重复执行。

内容：超时和重试为什么会造成重复请求；幂等键；请求状态的保存；处理中、成功和失败状态；重复请求时复用结果；Redis 记录与数据库唯一约束的配合。

实践：实现一个带 `request_id` 的创建任务接口，同一个请求号只能创建一次，并能查询已处理请求的结果。

代码计划：`code/redis/10-idempotency.py`。

### 第 11 课：分布式锁的基本模型

目标：理解 Redis 分布式锁的获取、过期和释放校验，并知道它不能替代数据库事务。

内容：`SET NX EX`；锁的唯一持有者标识；获取锁失败；锁过期；进程崩溃；释放锁时校验持有者；锁粒度和持有时间；锁误用的风险。

实践：为一个只能由单个 Worker 执行的任务增加基础锁，模拟锁获取失败和锁超时。

代码计划：`code/redis/11-distributed-lock.py`。

### 第 12 课：List、Stream 与异步任务

目标：理解生产者、消费者、任务状态和简单失败重试。

内容：同步任务和异步任务；生产者、消费者和队列；使用 List 实现简单任务队列；Redis Stream 的基本概念；消息确认；任务状态和重试次数。

实践：实现一个简单任务消费者，接收任务、更新状态，并在失败后进行有限次数重试。

代码计划：`code/redis/12-list-stream-tasks.py`。

### 第 13 课：消息可靠性与综合练习

目标：处理重复消费、失败消息和任务幂等，并串起本阶段的主要知识。

内容：消息丢失、重复消费、顺序和并发消费者；死信；消费幂等；消息处理日志；超时和失败重试；Redis、数据库和 Worker 的职责边界。

综合实践：实现一个带缓存、限流、幂等请求号、异步任务、失败重试和重复消费处理的 FastAPI 功能，并记录一次故障排查过程。

## 综合练习

完成一个“带缓存和异步任务的 API”：

```text
FastAPI 请求
    -> 限流检查
    -> 幂等请求检查
    -> 查询 Redis 或数据库
    -> 创建异步任务
    -> Worker 执行任务
    -> 保存任务状态和结果
```

要求至少包含：

- 一个数据库查询缓存；
- 缓存过期和主动失效；
- 不存在数据的空值缓存；
- 按用户或接口的固定窗口限流；
- 带唯一请求号的幂等接口；
- 一个简单任务队列和消费者；
- 失败重试和重复消费处理；
- 日志和至少一个接口测试。

## 阶段验收

学习者应能够：

1. 解释 Redis 与 SQLite、MySQL 的职责区别。
2. 根据场景选择 String、Hash、List、Set 和 Sorted Set。
3. 设计带业务前缀和生命周期的 Redis Key。
4. 使用 Python 客户端和连接池访问 Redis。
5. 实现 Cache Aside，并说明缓存失效时的行为。
6. 解释缓存穿透、击穿、雪崩、热点 Key 和大 Key。
7. 说明数据库与缓存一致性的常见策略及其局限。
8. 使用 `INCR` 实现计数和固定窗口限流。
9. 设计带唯一请求号的幂等接口。
10. 描述分布式锁的获取、过期、释放校验和误用风险。
11. 解释消息丢失、重复消费、失败重试和死信。
12. 说明为什么消费者必须在业务层保证幂等。
13. 完成一个带缓存、限流和异步任务的 FastAPI 功能。
14. 解释 Redis 为什么快（内存、数据结构、单线程、多路复用）。
15. 说明 RDB 与 AOF 的区别、混合持久化和内存淘汰策略。

## 课程编写约束

- 每课只引入少量新概念，先观察运行结果，再解释代码。
- 每课应包含学习目标、知识点、项目对应场景、可运行示例、课后作业和验收问题。
- 课程代码统一放在 `code/redis/`。
- 课程课文放在本目录，本 README 即大纲与材料索引。
- 缓存示例必须说明数据来源、失效策略和异常行为。
- 分布式锁示例必须说明过期、释放校验和误用风险。
- 消息队列示例必须讨论重复消费和业务幂等。
- 不把 Redis 当作关系型数据库，也不把分布式锁描述成分布式事务。
