# 第九课：集成与提升树

第 8 课末尾说单棵决策树高方差。本课讲解决它的两条路线：**Bagging**（并行地合多棵独立树，主要降方差）和 **Boosting**（顺序地补前面的错，同时降偏差）。随机森林是 Bagging 的代表，GBDT 是 Boosting 的代表，XGBoost 在 GBDT 之上做工程优化。本课是校招重点，XGBoost 相对 GBDT 的差异要能讲清楚。

本课主线：先用随机森林讲 Bagging 为什么降方差；再讲 Boosting 的"顺序补错"，到 GBDT 的"拟合负梯度"；然后列出 XGBoost 相对 GBDT 多出来的四点；LightGBM 只保留两个关键差异。集成原理用 sklearn 现成库做对照，不手写完整算法。

**学习目标：**

1. 能说明 Bagging 通过样本采样 + 特征采样降低方差，为什么能降；
2. 能说明 Boosting 顺序训练、每棵补前面的错，与 Bagging 的并行差别；
3. 能解释 GBDT 的"拟合负梯度"是什么意思，回归和分类各拟合什么；
4. 能列出 XGBoost 相对 GBDT 的四点改进（正则、二阶信息、缺失值默认方向、列采样），并解释每点解决什么；
5. 能说明 LightGBM 的叶子优先生长和直方图分桶各解决什么。

## 1. 集成：合多棵树的两种方式

第 8 课说单棵树高方差——样本稍微变化，树的结构就大变。把多棵树合起来用，叫**集成（ensemble）**。合的方式有两种根本不同的哲学：

```text
Bagging（并行）    多棵树各自独立训练，预测时投票/平均
                  主要目标：降方差（把多棵高方差树的波动平均掉）

Boosting（串行）   树按顺序训练，后面的树补前面的错
                  主要目标：降偏差（整体把欠拟合的部分补上）
```

判断一句话：**Bagging 的树之间互不影响，Boosting 的每棵树都依赖前面的结果。** 这决定了两者的并行性和误差特性。Bagging 可并行训练，Boosting 必须串行。

## 2. 随机森林：Bagging + 特征采样

**随机森林（random forest）**是 Bagging 在决策树上的具体化。两处采样：

- **样本采样（bootstrap）**：每棵树从训练集**有放回地**抽同样数量的样本，所以不同树的训练集略有不同——这是"多棵高方差但不太相关的树"里的"不太相关"。
- **特征采样**：每棵树分裂时，只随机挑一部分特征（sklearn 默认 $\sqrt{\text{特征数}}$）里选最佳分裂。如果所有树都用全部特征，它们会高度相似，投票等于没合；特征采样保证树之间的多样性。

为什么能降方差：单棵树的预测是"高方差、中等偏差"的，随机森林对很多棵树的预测取平均，平均化把方差摊薄，偏差几乎不变。第 8 课的重采样实验显示，同一份数据做 30 次 bootstrap 扰动，单棵树的预测分歧率约 0.12，随机森林约 0.07——单棵树结构随样本扰动大改，随机森林把波动平均掉了。

随机森林的预测方式：分类投票（每棵树投一个类别，多数胜出），回归取平均。它几乎不需要调参就有不错的基线，是表格数据的默认首选。

## 3. Boosting：按顺序补前面的错

Boosting 不平均多棵树，而是**一棵接一棵地练，后面的树专门处理前面犯的错**。经典直觉是 AdaBoost：训练完第一棵树，把被它分错的样本权重调高，第二棵树就更关注这些难样本；依此类推。整体预测是所有树的加权组合。

误差特性与 Bagging 不同：Bagging 主要降方差，Boosting 主要降偏差。原因：Boosting 的每棵树都不是"独立随机波动"，而是刻意补缺口，最终整体能表达单棵树表达不了的复杂关系。但这也带来一个代价：**Boosting 对噪声样本敏感**——如果某个样本是标注错误，Boosting 会一棵树一棵树地拼命拟合它，过拟合风险比随机森林高。本课代码里噪声数据上随机森林测试准确率 0.79、GBDT 0.78，作业的棋盘数据上同一现象更明显（噪声升高时 GBDT 降幅更大），就是这个原因。

## 4. GBDT：拟合负梯度

**GBDT（gradient boosting decision tree，梯度提升树）**是 Boosting 的一种具体实现。关键问题是"补错"怎么定义得可计算。AdaBoost 靠调样本权重，GBDT 换一种更通用的方式：

**每一棵新树拟合的是"前面所有树的残差"，数学上叫负梯度。** 对回归：第一棵树预测 $\hat{y}_1$，残差 $y - \hat{y}_1$ 是"第一轮没预测对的部分"，第二棵树就去拟合这个残差；预测 = 第一棵树 + 第二棵树 + …。对分类：不直接拟合 0/1 标签，而是拟合"对数几率空间里的残差"，也就是拟合负梯度（负梯度是损失函数下降最快的方向）。

一句话：**GBDT 的每棵树都在拟合前面模型的负梯度，把"还差多少"当成回归目标。** 损失函数不同，负梯度的具体形式就不同（平方损失的负梯度是残差，交叉熵的负梯度是概率差），但框架是同一个。这也是 GBDT 能配不同损失的原因。

学习率（这里常叫 shrinkage）控制每棵树贡献多大：每棵树的预测乘一个小学习率再加进去，让整体学得更慢更稳。树多、学习率小，是 GBDT 的常见配置。

## 5. XGBoost：相对 GBDT 多出来的四点

**XGBoost（extreme gradient boosting）**是 GBDT 的高性能实现，面试必问"它比 GBDT 多什么"。四点：

1. **正则项**：目标函数在损失上加 $\gamma$·叶子数 + $\lambda$·叶子权重平方。叶子越多、权重越大，惩罚越重——直接限制树的复杂度，降低过拟合。GBDT 靠控制树深、学习率间接限制，XGBoost 把限制写进目标。
2. **二阶信息**：分裂时用损失的一阶导（梯度）和**二阶导（Hessian）**。GBDT 只用一阶梯度；XGBoost 用二阶导让分裂更准，收敛更快。实现上对每个叶子算最优权重也用到二阶导。
3. **缺失值默认方向**：训练时自动学习缺失值往左还是往右走（哪个方向增益大就定哪个），预测时按学到的方向走。GBDT 通常要求先处理缺失值。
4. **列采样**：分裂时只用一部分特征（和随机森林的特征采样类似），增加树间差异、降方差、也省计算。

记忆口诀：**正则、二阶、缺失值、列采样**。前两个是精度上的改进，后两个是稳健性和效率上的改进。讲差异时按"解决什么问题"讲，不背公式。

## 6. LightGBM：两个关键差异

**LightGBM** 是另一个高性能 GBDT 实现，和 XGBoost 的差别很多，本课只保留两个核心：

- **叶子优先生长**：XGBoost 按层生长（同一层所有节点都分裂），LightGBM 每次只选增益最大的那个叶子分裂。层生长更均衡但可能浪费（有些分支增益小）；叶子优先更精准但可能长出不均衡的深树，要靠 `max_depth` 和 `min_data_in_leaf` 限制。
- **直方图分桶**：连续特征先离散成固定数量的桶（如 255 个），分裂时只遍历桶不遍历每个样本值。桶化损失一点精度，换来速度大幅提升，内存也省。

一句话：**LightGBM 用"每次分裂最大增益叶子 + 特征分桶"换取速度和内存，精度略降但通常可控。** 工业界两个库都在用，选型看数据量和硬件，本课不展开部署细节。

## 10. 面试高频考点

- Bagging vs Boosting：并行独立 vs 串行补错；降方差 vs 降偏差。
- 随机森林：样本有放回采样 + 特征随机子集；投票/平均；几乎免调参。
- GBDT：每棵树拟合负梯度（回归=残差，分类=对数几率空间的残差）；学习率控制每棵贡献。
- XGBoost 四点：正则（叶子数+权重平方）、二阶导（Hessian）、缺失值默认方向自动学习、列采样。
- LightGBM 两点：叶子优先生长（可能不均衡，要限制深度）、直方图分桶（速度换精度）。
- 噪声敏感性：Boosting 拟合噪声样本，噪声大时随机森林更稳。
- 选型：表格数据默认随机森林起手；需要更强精度再上 XGBoost/LightGBM；数据量大有 GPU 优先 LightGBM。
