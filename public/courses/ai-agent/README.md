# AI Agent 实战

目标：面向 AI 应用开发岗秋招，建立"一次 Agent 请求如何思考、调用工具、循环执行，并在生产中安全、可靠、可观测地落地"的完整知识体系。本课对应 `learning-plan-interview.md` 中的课程一，并吸收原"课程四：AI 应用系统设计"中 Agent 专属的部分。本课与 LangGraph 课互补：LangGraph 课教"如何用图表达和实现 Agent"，本课教"概念、机制与生产级系统设计"；框架 API 一律不写，需要对照时指向 LangGraph 对应课。

本课程共十二课，原则是**概念边界先行、机制随后、组件分开、生产化收束在后**，分四段：第 1~2 课建立概念与循环心智模型（LangGraph 前置）；第 3~6 课深入工具、记忆、上下文与多 Agent 四大组件；第 7~10 课进入生产化：权限与多租户、沙盒与执行环境、可靠性与人工介入、观测与评测；第 11~12 课讲部署、模型网关与成本治理，并以综合项目和面试复盘收束。

## 前置知识

- 会用 Python 编写函数、类、异常处理和 JSON；理解 HTTP 请求、接口输入输出和基本业务服务分层。
- 第 1、2 课不要求使用过 LangChain / LangGraph，第一课会用 OpenAI 兼容接口接入 DeepSeek；未配置密钥时课程示例仍可运行。
- 第 3 课起（尤其第 4、6、9、10 课的对照练习）建议已完成 LangGraph 课，能读懂"节点、边、状态、checkpoint"的框架表达。
- 第 5 课涉及 RAG 概念桥接，详细链路（chunking、embedding、检索、rerank）放到 RAG 课（`learning-plan-interview.md` 课程三）。
- 第 9 课涉及分布式锁、消息队列、缓存一致性等通用后端能力，机制细节在 Redis 与分布式课，本课只讲 Agent 场景中的落法。
- 模型调用沿用 OpenAI 兼容接口；脚本化/假模型兜底，默认不依赖网络和 API Key。

## 课程结构

四段十二课，每课标注面试考点，讲解从机制讲起，不直接给背诵结论。

### 第一段 概念与循环（第 1~2 课）

#### 第 1 课：Agent 概念与 LLM 调用

目标：定义 Agent 并区分 Chatbot / 传统程序 / Workflow / Agentic Workflow；按四个部件说明职责；能用 OpenAI 兼容接口调用模型并组装 messages；理解 Function Calling 与结构化输出的协议形态。

内容：判断标准"下一步由谁决定、会不会改外部世界"；`Agent = LLM + Planning + Memory + Tools + Runtime`，缺一部分如何退化。LLM 调用：`OpenAI` 构造与 `chat.completions.create` 的常用签名、`base_url` 切换、`messages`（system / user / assistant）与采样参数、返回值。结构化输出与 Function Calling 协议：模型只输出调用意图，真正执行的是 Runtime。

实践：组装多轮 messages 并可选真实调用；作业完成带校验的调用函数和两轮对话的 messages 组装；未配置 `DEEPSEEK_API_KEY` 时默认入口跳过网络请求。

面试考点：Agent 与 Chatbot、Workflow 的区别；四个部件缺一如何退化；为什么模型返回的 JSON 不是函数调用；多轮对话为何回传 `assistant` 消息；如何换 `base_url` 接入 DeepSeek。

#### 第 2 课：Agent Loop、规划与决策

目标：画出完整 Agent Loop，说明模型、运行时、工具和停止条件各自的职责；能比较 ReAct / Plan-and-Execute / Reflection 并说明计划过期时如何重规划。

内容：标准循环：接收目标 → 组装上下文 → 模型决策 → 解析输出 → 最终回答则停止 / 工具调用则执行 → 观察写回 → 再决策。状态管理："消息追加"与"覆盖状态"不是一回事，步数、停止标志等必须由运行时维护。停止条件：最终回答、`max_steps`、超时、token/费用预算、重复调用检测、用户取消。规划策略对比：ReAct（边想边做，适合工具顺序依赖中间结果的短任务）、Plan-and-Execute（先计划后执行，适合需展示计划的任务）、Reflection（结果自评修正，适合质量敏感场景）的延迟、token、可控性与失败恢复；"先规划"不能消灭工具错误，计划过期必须允许重规划。死循环防护。在此建立幻觉、工具误用、上下文污染的排查骨架，细节在后续课展开。

实践：实现最大步数受限的最小循环（假模型按脚本输出决策，运行时打印每一步的输入、决策、观察和是否停止）；用同一组任务分别走 ReAct 与 Plan-and-Execute 两条模拟路径，观察步数、是否提前暴露计划和中间失败后的行为差异。

面试考点：Agent Loop 的完整流程；为什么模型不能直接改数据库；循环里哪些状态必须由运行时维护；ReAct / P&E / Reflection 分别适合什么场景；为什么生产里不能所有任务都做成开放 ReAct。

### 第二段 核心组件（第 3~6 课）

#### 第 3 课：工具系统：注册、描述、调用链路与可靠性

目标：讲清一次工具调用由哪些组件完成，工具描述为什么决定模型选对选错；理解工具异常、幂等与编排。

内容：工具注册清单：name、description、参数 schema、权限标记、同步或副作用；模型只看到描述与 schema，看不到函数源码，因此 description 必须说明何时用、何时不用、参数含义与失败语义。调用链路：解析调用 → 确认工具存在 → 参数校验 → 权限检查 → 执行业务函数 → 把成功、失败、超时变成 Observation。工具异常两种策略：回填错误消息让模型自我修正 vs 直接抛出快速失败；超时包装。工具幂等：唯一请求号、重复执行无副作用。工具结果处理：截断、结构化返回。工具编排：串行、并行、条件。Function Calling / MCP / Skills 的边界：FC 是模型输出调用意图的协议，MCP 是连接外部工具/资源的协议，Skills 是可复用能力包。

实践：注册两个工具（含糊 vs 清晰 description）对比假模型的选工具结果；对错误参数、无权限、执行异常分别回填观察，而不是让循环崩溃；给工具加幂等键与超时包装。

面试考点：工具 description 为什么关键；工具调用由哪些组件完成；MCP / Skills / Function Calling 边界；工具失败后应该返回给模型什么；工具幂等怎么设计。

#### 第 4 课：记忆系统：短期、长期与污染控制

目标：说明"有记忆"不是保存全部聊天记录；能设计短期/长期记忆、写入与召回策略，并控制记忆污染。

内容：短期记忆是当前会话消息、本轮工具结果和任务状态，受上下文窗口限制，需要修剪与摘要；长期记忆是跨会话的偏好、事实与摘要，必须可写入、可召回、可过期、可冲突处理。向量记忆与结构化（DB / Markdown）记忆的适用场景：前者适合模糊相似召回，后者适合规则、偏好和可人工审阅的事实。Auto Memory：重要性阈值、去重、用户确认、事后审核，不能无限自动写入。团队共享记忆：流程规范、提示词模板适合 Git 和 Code Review；用户数据和运行时事实适合数据库。记忆污染控制：写入前校验、来源标注、人工审核、可回滚，保证错误长期记忆不进入下次决策。

实践：给模拟 Agent 增加会话消息缓冲和一份可读写的长期笔记；对比"整段聊天塞进下次 Prompt"与"只注入相关摘要"的上下文长度差异；演示一条错误长期记忆如何导致再次选错工具，并演示拦截与回滚。

面试考点：短期/长期记忆的区别；记忆系统要解决哪些核心问题；向量记忆与结构化记忆分别适合什么；Auto Memory 为什么不能无限写入；哪些团队共享记忆走 Git、哪些走数据库；记忆污染怎么防。

#### 第 5 课：上下文工程与安全输入

目标：区分"把指令写清楚"和"把对的状态装进窗口"；掌握裁剪、压缩与隔离；能防护 Prompt 注入；建立 RAG 概念桥接并理解 Agentic RAG。

内容：Prompt Engineering：Role、Task、Context、Format 四要素；Few-Shot、CoT、任务分解、结构化输出的适用场景。为什么 Agent 场景只优化 Prompt 不够：窗口里还有历史、计划、工具结果、记忆和检索证据，会互相挤占和污染。Context Engineering：静态规则、动态信息、工具结果、记忆如何进入上下文；长任务溢出时 Compaction 压缩旧观察、结构化笔记保留任务进度、sub-agent 隔离子任务上下文。Prompt 注入防护：系统指令与不可信内容隔离、工具结果当数据不当指令、危险操作二次确认；注入不只来自用户输入，也来自工具结果、网页内容和被污染的记忆（越权与审计在第 7 课展开）。RAG 概念桥接：离线入库 + 在线查询的一句话链路；Agentic RAG：检索即工具、检索决策、查询改写、重检索；详细 RAG 链路在 RAG 课展开。

实践：把同一任务分别用"超长聊天记录"和"系统规则 + 结构化状态 + 最近观察"组装上下文，观察决策是否仍正确；演示一条工具返回文本中的注入语句若不当作数据会发生什么。

面试考点：Prompt Engineering 和 Context Engineering 的区别；四要素分别解决什么；Few-Shot、CoT、结构化输出何时用；Prompt 注入怎么防；静态规则、动态信息、工具结果、记忆如何进入上下文；Compaction、结构化笔记、Sub-agent 分别怎么用；Agentic RAG 与固定 RAG 的取舍。

#### 第 6 课：多 Agent 协作与编排

目标：能选择协作形态，说清生产里不能盲目上多 Agent 的原因；理解常见编排模式与协作问题。

内容：单 Agent / Agentic Workflow / Multi-Agent 的取舍：单 Agent 适合工具不多、目标单一的任务；Agentic Workflow 适合主路径确定、局部需要模型判断的业务，是生产默认优先项；Multi-Agent 适合需要角色隔离、并行调研或互相审查的任务。编排模式：orchestrator-worker、pipeline、层级结构。通信方式：消息传递、共享状态/黑板、结构化中间产物。协作主要问题：任务重复、上下文不一致、互相等待、级联失败、错误被下一个 Agent 当成事实。子 Agent 隔离：上下文、资源、权限。和 Life Manager 对齐：日程写入、记录查询应优先单 Agent 或 Workflow。

实践：把"先查记录再决定是否加计划"分别实现为单 Agent 循环和"规划 Agent + 执行 Agent"两个假角色，统计步数、失败传播和最终是否一致。

面试考点：什么时候用纯 Agent、Workflow 或 Agentic Workflow；Multi-Agent 协作的主要问题；为什么生产里不能盲目上多 Agent。

### 第三段 生产化（第 7~10 课）

#### 第 7 课：权限、多租户与安全

目标：建立 Agent 系统的权限模型与多租户隔离；理解审计、数据安全与对抗性输入防护。

内容：权限模型：RBAC / ABAC、工具级权限、数据级权限（行/列）、API 权限；用户与用户组、角色、成员关系。多租户隔离：数据层（租户 ID 贯穿、行级权限或独立 schema/库）、记忆层（按租户分区、严禁跨租户召回）、资源层（配额）。租户配额与计费：限流、token 预算、优先级。敏感操作二次确认。审计日志：谁在何时调用了哪个工具、入参出参、结果。数据安全：PII 脱敏、加密、secrets 管理。对抗性输入：恶意工具参数、越权工具调用、Prompt Injection 变体。

实践：给工具加权限标记与租户参数校验；模拟跨租户召回与越权调用并拦截；设计一份审计日志字段清单。

面试考点：RBAC 与 ABAC 的区别；多租户在数据/记忆/资源层怎么做隔离；审计为什么必要；Prompt 注入的防护层级（系统隔离、结果当数据、Runtime 权限）。

#### 第 8 课：沙盒与执行环境

目标：理解沙盒的定位、隔离技术选型与资源控制；能设计沙箱资源池与调度。

内容：沙盒定位：代码/工具执行、不可信输入隔离。隔离技术对比：容器、轻量虚拟化（Firecracker / gVisor）、进程级隔离的取舍（隔离强度 vs 启动速度）。资源限制：CPU、内存、网络（禁外网或白名单）、时间（超时强杀）；文件系统隔离与临时目录；结果防逃逸：输出校验、序列化边界。沙箱资源池：预热池（warm pool）、复用回收、空闲 TTL 销毁；调度：请求排队、优先级、超过上限拒绝或降级。

实践：用容器或进程包装一个受限工具执行，配置资源限制与超时强杀；演示输出越界被拦截；设计一个资源池的参数（池大小、TTL、配额）。

面试考点：为什么工具/代码执行必须沙盒；gVisor / Firecracker 与容器的取舍；资源池如何防冷启动与防饿死；超时强杀的意义。

#### 第 9 课：可靠性与人工介入

目标：理解 Agent 系统的可靠性：幂等、超时重试、备份恢复、崩溃恢复与行为漂移；能设计人工审批流。

内容：超时、重试、退避、熔断、降级；幂等与去重（唯一请求号）；异步任务与任务状态机、失败重试、死信。备份与恢复：checkpoint 状态库备份、业务数据备份、备份策略与恢复演练。崩溃恢复：thread_id 续跑、未落盘步骤重跑、已执行的工具副作用不重放（靠幂等兜底）。行为漂移检测与纠正：goal 固定（放系统指令/结构化状态，不靠模型"记住"）、重复动作检测、reflection 自检、关键节点人工确认。人工介入与审批流：什么操作必须人工确认（不可逆、涉及资金/删除/外发、高不确定度）；审批请求挂起（状态外置，对应框架 interrupt 机制，见 LangGraph 第 6 课）、审批队列与通知；审批超时策略——失败代价不对称时自动拒绝，能自动回滚的操作才可自动通过；人工修正回写为 Observation 或记忆更新；批量任务的抽样人工审核与事后审计。通用后端部分（分布式锁、消息队列、缓存一致性）指向 Redis 与分布式课，本课只讲 Agent 场景中的落法。

实践：给工具加超时包装与幂等键；模拟进程崩溃后用同一 thread_id 从断点恢复，说明副作用处理；设计一份审批流（哪些工具触发审批、超时自动拒绝、审批结果回写并演示挂起恢复）；设计一份备份与恢复演练记录。

面试考点：工具幂等为什么重要、怎么设计；崩溃后恢复时外部副作用如何处理；checkpoint 与业务库的分工；行为漂移怎么检测与纠正；哪些操作必须人工确认；审批超时应该自动通过还是自动拒绝，依据是什么。

#### 第 10 课：观测与评测

目标：建立 Agent 的可观测性（日志、trace、指标）与评测体系；能做回归对比与 badcase 归因。

内容：日志：请求日志、工具调用日志、每步决策；trace：完整执行轨迹、每步入参出参，用 trace_id 串联一次请求跨服务的所有记录；指标：成功率、任务完成率、延迟、token、成本；监控告警与 SLO：Agent 不能只看 200/500，要盯 trace 与任务完成率。badcase 复盘与定位顺序：先看 trace 每步决策/观察，再看工具描述与权限，再看记忆写入。评测集构建：固定样例、边界用例、对抗用例，样例要覆盖选错工具、参数错误、注入输入。评估方法：规则断言（可判分、便宜、覆盖窄）vs LLM-as-judge（灵活、需校准与抽样人工对照）；轨迹级评估：比较整条工具调用序列而不是只看最终答案；回归对比：改提示词/加工具/换模型后跑同一评测集，把评测当发布门禁。

实践：为最小 Agent 加 trace 与指标采集；写评测脚本跑固定评测集并做一次修改后的回归对比；写一份 badcase 复盘。

面试考点：Agent 观测为什么不能只看可用性；评测集怎么选；LLM-as-judge 的优缺点；轨迹级评估与只看最终答案的差别；如何防止改一个工具导致整体行为回归。

### 第四段 部署与综合（第 11~12 课）

#### 第 11 课：部署、模型网关与成本治理

目标：理解 Agent 服务的部署与扩展；理解 LLM Gateway、模型路由与降级链；掌握成本优化的抓手。

内容：部署：环境隔离、配置管理、secrets、灰度发布与回滚；模型版本管理与升级影响评估（换模型先跑回归评测）。模型网关（LLM Gateway）：业务代码不直接依赖具体供应商，统一接入层负责多供应商路由、协议适配（OpenAI 兼容）、密钥与配额管理、调用日志与计费统计。模型路由与降级链：按任务复杂度分级（简单任务用小模型或规则兜底）、主模型超时/故障时切换备用模型、缓存命中优先。prompt caching：系统指令与工具清单等稳定前缀复用，降低输入 token 成本与首字延迟。成本治理：token 成本构成（输入、输出、工具结果膨胀）、上下文裁剪与压缩的经济学、按租户配额与计费（衔接第 7 课）、成本指标与预算告警。Agent 服务化与扩展：无状态化、checkpoint/会话状态外置存储、水平扩展、工具调用异步化；流式事件输出一句话点到（实现见 fastapi 第 10 课与 LangGraph 第 11 课）。

实践：给假模型加一层"网关"对象，按任务路由到不同假模型并记录 token 成本，演示主模型超时切换备用模型；对比上下文裁剪前后的 token 账单；写一份部署清单（环境、配置、secrets、灰度）。

面试考点：为什么需要 LLM Gateway、它解决什么问题；模型降级链怎么设计；prompt caching 为什么省钱省延迟；Agent 服务怎么做无状态水平扩展；Agent 成本优化有哪些抓手；换模型上线前要做什么。

#### 第 12 课：综合项目与面试复盘

目标：把全课串成"一个生产级 Agent 的完整生命周期"，完成 Life Manager 生产级改造，并独立给出综合面试回答。

内容：综合项目：Life Manager 最小 Agent 升级为生产级——工具沙盒执行、权限与租户隔离、checkpoint 状态备份与恢复、人工审批挂起与恢复、trace 观测、固定评测集回归。全链路串讲：用户请求 → 路由 → 工具调用 → 记忆 → 人工审批 → 流式返回 → 观测，梳理每步的故障与排查手段。全课面试题串讲。

实践：完成综合项目并产出：可运行代码、全链路 trace 记录、一次备份与恢复演练记录、一次 badcase 归因复盘、一份系统设计说明（权限/沙盒/可靠性/评测/成本的取舍）。

面试考点：如何设计一个带权限、评测、日志、限流、成本控制的 AI 应用；如何结合 Life Manager 说明 Agent、工具、RAG、数据库的关系；完整系统设计题的回答框架。

## 综合练习

完成"Life Manager 生产级最小 Agent"：支持工具注册与沙盒执行、权限与租户参数校验、幂等与超时、checkpoint 备份与崩溃恢复、人工审批挂起与恢复、trace 与指标采集、固定评测集回归；能跑通"查询本周运动并按需添加计划"，且至少覆盖两类失败防护（越权拦截、死循环）。该练习与 LangGraph 课的综合项目对照：LangGraph 项目解决"怎么用图实现"，本课项目解决"生产里怎么把它做得安全、可靠、可观测"。

## 阶段验收

学习者应能够：

1. 用一句话定义 Agent，并区分 Chatbot、传统程序、Workflow、Agentic Workflow。
2. 解释 `LLM + Planning + Memory + Tools + Runtime`，画出 Agent Loop，说明模型为什么不能直接执行后端函数。
3. 比较 ReAct、Plan-and-Execute、Reflection 的场景与代价，说明计划过期为什么要重规划。
4. 解释工具 description、参数校验、权限、Observation 与幂等的作用，区分 Function Calling / MCP / Skills。
5. 设计短期/长期记忆与污染控制，说明团队共享记忆的存放选择。
6. 区分 Prompt Engineering 与 Context Engineering，处理注入、裁剪与压缩，说明 Agentic RAG 的取舍。
7. 判断单 Agent、Multi-Agent、Agentic Workflow 的取舍，说出多 Agent 协作的主要问题。
8. 设计工具级/数据级权限与多租户隔离，说明审计与数据安全的位置。
9. 说明沙盒的隔离技术与资源控制，能设计资源池与调度。
10. 设计幂等、超时重试、备份恢复与崩溃恢复，处理行为漂移，并能设计人工审批流。
11. 建立日志、trace、指标与评测体系，能做回归对比与 badcase 复盘。
12. 说明 LLM Gateway、模型路由与降级链、prompt caching 的作用，给出 Agent 成本优化与水平扩展方案。
13. 独立完成 Life Manager 生产级改造，给出完整系统设计与面试回答。

## 课程编写约束

- 本课不引入 LangGraph / LangChain 的类名与 API；需要对照实现时写"见 LangGraph 课第 N 课"，例如：工具机制见第 4、8 课，记忆持久化见第 6 课，Agentic RAG 见第 9 课，并行/子图见第 10 课，评测机制见第 12 课。
- 通用后端能力（分布式锁、消息队列、缓存一致性、Docker 部署）不展开，指向 Redis、分布式、Docker 与阶段 10 课程。
- 讲解要有逻辑、够详细：每个概念先定义，再讲输入输出和职责边界，再给最小例子，最后给项目场景和面试追问。
- 每课只引入少量新概念；工具、记忆、上下文、多 Agent、权限、沙盒、评测不在同一课一次性讲完。
- 课程是项目型：示例围绕生活管家的记录、计划和偏好，但保持最小实现，不要求复刻完整 Life Manager。
- 实践优先使用 Python 标准库；模拟 LLM 用规则、脚本化决策或本地假对象；需要真实模型时必须注明可选，且默认入口不依赖网络和 API Key。
- 安全相关（沙盒、注入、越权）只讲防护思路和本课能演示的隔离方法，不写可被直接滥用的攻击 PoC。
- 每课配套课程文档；第 1 至第 12 课均编写 `code/ai-agent/` 下的标准代码文件（上半部分可运行示例，下半部分同文件作业，作业默认不执行；第 12 课为综合项目文件）。
- 文档结构遵循 `课程编写要求.md`：学习目标、分节讲解、场景、运行方式、课后作业、验收问题。
- 每课标注面试高频考点，但必须从机制讲起，不直接给背诵段落。
- 在必要处使用 SVG 示意图（Agent Loop、工具调用链路、多租户隔离、沙盒资源池、checkpoint 备份恢复、审批挂起与恢复、观测与评测闭环、模型路由与降级），放在本目录 `assets/` 下，沿用本仓库已有风格。
