# Linux 与运行环境课程大纲

目标：面向 AI 应用开发岗秋招，建立"代码如何在 Linux 环境中被运行、观察和诊断"的完整心智模型，覆盖 Linux 面试高频考点。本课程属于基础知识部分，只讲运行环境本身：命令行、文件系统、文本处理、日志、权限、进程、端口和资源观察。DNS、TCP/IP、HTTP 等网络细节在阶段 3 的网络课程中展开；SSH、systemd 服务单元、容器和部署在阶段 10 展开。示例使用通用、贴近真实工程的场景（启动服务、查看日志、排查接口问题等），不与具体项目强行关联。

本课程共十一课，原则是**理论先行、实践在后**：第 1 至第 7 课把命令行与运行环境学完（命令、文件、管道、文本、日志、权限、环境变量），第 8 至第 10 课进入进程、端口和系统资源，第 11 课把排查命令汇总成综合排错与复盘。文本处理、日志和权限是面试高频区，分别单独成课；工具类命令（如 `grep`、`tail`、`ss`）在引入的课程中讲透，后续课程用到时只做一句话说明并引用对应课程。

## 前置知识

完成阶段 0 的 Git 基础和阶段 1 的 Python 基础；会用终端运行命令，理解文件和目录的基本含义；会用 Python 编写和运行简单脚本，了解异常和 traceback。

## 课程结构

### 第 1 课：Linux、终端、Shell 与命令基础（[已编写](./lesson-01-command-line-and-environment.md)）

目标：建立 Linux、终端、Shell、命令和当前工作目录的基本心智模型，能够阅读一条命令的结构（命令名、选项、参数、输出），并回答"我现在在哪里、项目文件在哪里"。

内容：Linux、终端、Shell 与命令的关系；命令的输入、输出和副作用（观察型命令与修改型命令）；当前工作目录；绝对路径与相对路径、`.` 与 `..`；文件系统目录层次（`/`、`/home`、`/etc`、`/var/log`、`/tmp` 的用途）；`pwd`、`ls`、`cd` 的基本语法和输出。

实践：在项目根目录与临时目录之间切换，用 `pwd` 和 `ls` 验证位置；解释 `cd courses`、`cd ..` 和 `cd /absolute/path` 的含义；用 `ls -la` 观察隐藏文件。

面试考点：当前工作目录是什么、为什么影响相对路径；绝对路径和相对路径的区别；如何阅读一条命令；如何区分只观察的命令和会修改文件的命令。

### 第 2 课：文件与目录：查找、复制与安全操作（[已编写](./lesson-02-files-search-safe-ops.md)）

目标：掌握文件与目录操作命令的语法和风险，能够用 `find` 按位置查找文件、用 `rg`/`grep` 搜索文件内容。

内容：`mkdir`、`touch`、`cp`、`mv`、`rm` 的语法、参数和副作用（创建、覆盖、移动、删除）；`find` 的常用条件（`-name`、`-type`、`-maxdepth`）；`rg`/`grep` 的常用选项（`-n`、`-i`、`-l`）与"搜索位置还是搜索内容"的分工；文件操作安全习惯（临时练习目录、执行删除前确认目标路径）。

实践：只在临时练习目录中创建和组织文件；用 `find` 和 `rg` 在课程资料中定位文件与内容；观察 `mv`、`rm` 对文件系统的实际影响。

面试考点：`find` 和 `grep` 的区别；`rm -rf` 为什么危险；如何找到一个文件或一段内容；哪些命令会修改文件、哪些只读。

### 第 3 课：标准输入输出、管道与重定向（[已编写](./lesson-03-stdio-pipes-redirection.md)）

目标：理解 stdin、stdout、stderr 三个标准流，掌握重定向和管道的语法、作用与副作用。

内容：三个标准流的含义与文件编号；`>` 与 `>>` 的覆盖和追加行为及文件创建副作用；`2>`、`2>&1` 错误重定向；管道 `|` 把左侧 stdout 交给右侧 stdin；组合示例（`find | rg`、`命令 > 正常.log 2> 错误.log`）。

实践：把命令的 stdout 和 stderr 分别保存到临时文件，再合并保存；用管道串联两条命令筛选结果；验证 `>` 覆盖已有文件的行为。

面试考点：重定向与管道的区别；`2>&1` 的含义；`命令 > 文件` 和 `命令 2> 文件` 分别重定向什么；管道中左右命令的执行关系。

### 第 4 课：文本处理：查看、排序与统计（[已编写](./lesson-04-text-processing.md)）

目标：掌握查看文本、排序、去重和统计的常用命令，能够用管道组合完成"统计某类行有多少"的任务。

内容：查看文件（`cat`、`less` 分页、`head`、`tail`）；行数统计 `wc -l`；排序 `sort` 与反向 `sort -r`；去重计数 `uniq -c`（必须先 `sort`）；按列提取 `cut`；组合用法 `sort | uniq -c | sort -rn` 统计出现次数最多的行。

实践：对一份日志或课程文件执行行数统计、按字母排序、去重计数；用 `head`/`tail` 观察文件开头和结尾各五行。

面试考点：如何统计一个文件有多少行；如何统计文本中每类内容出现的次数并降序排列；`head` 和 `tail` 的作用；`less` 比 `cat` 好在哪。

### 第 5 课：日志查看与排查（[已编写](./lesson-05-log-inspection.md)）

目标：理解日志从哪里来、写到哪里去，掌握查看、搜索、跟踪日志的常用方法，能够回答"如何查询日志、如何查看最近的日志（反向排序）"。

内容：日志是什么（应用把 stdout/stderr 重定向到文件、日志框架写文件、系统服务写 `/var/log/`）；查看日志：`tail -n 100` 取末尾最新日志、`tail -f` 实时跟踪、`less` 分页浏览、`grep` 过滤关键词并配合 `-A`/`-B`/`-C` 查看上下文；反向输出整个文件用 `tac`；按修改时间找最新日志文件 `ls -lt /var/log`；systemd 服务的日志用 `journalctl`（`-u` 按服务、`-r` 反向排序、`-xe` 最近错误、`-f` 跟踪）；日志轮转的简单概念（日志为什么不会无限增大）。

实践：运行一个把正常输出和错误写入文件的 Python 脚本，用 `tail -f` 跟踪新增日志，用 `grep` 过滤并查看上下文，用 `tac` 反向查看；人为制造"服务没有日志"的场景，判断 stdout/stderr 的去向；用 `journalctl -u` 查看一个本机服务的最近日志。

面试考点：如何查询日志；**如何查看最近的日志（反向排序）**（`tail -n`、`tac`、`journalctl -r`、`ls -lt` 找最新文件）；如何实时跟踪日志；`grep` 如何带上下文查看；应用日志和 systemd 日志有什么区别。

### 第 6 课：文件权限与用户基础（[已编写](./lesson-06-file-permissions.md)）

目标：理解权限位和数字权限，会读 `ls -l` 的输出，掌握 `chmod`、`chown` 的基本用法，能够定位"Permission denied"。

内容：文件所有者、所属组和其他用户；读、写、执行三个权限位与 `ls -l` 输出；数字权限（`755`、`644`）的含义与换算；`chmod` 的数字和符号用法；`chown` 修改所有者；`whoami`、`id`；`sudo` 的概念、用途与风险。

实践：创建文件观察默认权限，修改权限后观察 "Permission denied"；用 `chmod 600` 保护一个文件；用 `sudo` 读取 `/var/log` 下的系统日志。

面试考点：`755` 和 `644` 分别表示什么；为什么会出现 Permission denied；`chmod` 和 `chown` 的区别；`sudo` 的用途和风险。

### 第 7 课：环境变量与 Python 运行环境（[已编写](./lesson-07-environment-variables.md)）

目标：理解环境变量、PATH 与 Python 解释器的关系，能够确认当前实际使用的 Python，理解虚拟环境如何通过 PATH 切换解释器。

内容：环境变量是什么（`echo`、`env`、`export`）；PATH 的搜索顺序与 `which`；`python --version` 与 `sys.executable` 的区别；venv 虚拟环境对 PATH 的影响；常见环境变量（`HOME`、`USER`、`PYTHONPATH`）与敏感信息的注意事项。

实践：用 `echo`、`env`、`which`、`python --version`、`python -c 'import sys; print(sys.executable)'` 检查环境；创建并激活一个 venv，观察 `which python` 和 `sys.executable` 的变化。

面试考点：PATH 是什么、为什么会出现找不到命令；`which python` 与 `sys.executable` 的区别；为什么只输出版本号不足以确认环境；虚拟环境如何工作。

### 第 8 课：程序、进程与退出

目标：区分程序、进程和线程，理解进程的生命周期，掌握观察进程、前后台运行、停止进程和读取退出码的方法。

内容：程序与进程的区别、PID 与 PPID；`ps` 的常用参数与输出、`top` 实时观察；前台与后台（`&`、`jobs`、`fg`、`bg`、`Ctrl+C`/`Ctrl+Z`）；`nohup` 与重定向实现后台常驻；信号与 `kill`（`TERM` 与 `KILL` 的区别）；退出码 `$?` 与 Python 脚本的退出；stderr 上的 traceback；僵尸进程的基本概念。

实践：运行正常退出、异常退出和持续运行的 Python 脚本，用 `ps` 观察进程状态并读取退出码；把一个脚本放到后台再拉回前台；用 `kill` 安全停止自己启动的课程进程。

面试考点：如何查看进程；`kill` 与 `kill -9` 的区别；退出码有什么作用；`nohup` 和 `&` 的区别；什么是僵尸进程。

### 第 9 课：端口、本地服务与基本诊断

目标：理解 IP 地址、端口和监听状态，掌握 `ss`、`lsof`、`curl` 等命令，能够定位端口占用和服务无法访问的问题。

内容：IP 地址与 `127.0.0.1`、`0.0.0.0` 的含义（网络细节在阶段 3）；端口是什么、为什么需要；监听状态 LISTEN；`ss -tlnp` 与 `lsof -i` 查看端口与进程；`curl` 访问本地服务并观察响应；"Address already in use" 的原因；`netstat` 与 `ss` 的对比。

实践：启动一个最小 HTTP 服务，用 `ss -tlnp` 确认监听，用 `curl` 访问并观察响应；故意启动第二个占用同一端口的服务，观察报错并用 `lsof -i` 定位占用者。

面试考点：端口被占用如何排查；如何查看哪个进程在监听某个端口；`127.0.0.1` 和 `0.0.0.0` 的区别；`ss` 和 `netstat` 的对比。

### 第 10 课：系统资源观察：磁盘、内存与负载

目标：会用 `df`、`du`、`free`、`top` 观察系统资源，能回答磁盘满、内存不足等常见问题的排查思路。

内容：`df -h` 查看磁盘空间；`du -sh` 查看目录大小并用它找大目录；`free -h` 查看内存与交换分区；`top` 实时查看进程的 CPU/内存占用与 load average；`uptime` 的负载含义；常见资源问题的表现（磁盘满导致写日志失败、内存不足导致进程被杀）。

实践：用 `df`/`du` 观察本机磁盘和最大的目录；用 `top` 排序观察 CPU/内存占用；结合第 5 课，制造磁盘写不进去的场景观察日志中的报错。

面试考点：磁盘满怎么排查（`df`、`du` 找大文件）；`free` 里的 buff/cache 是什么；load average 的含义；服务变慢时先看什么。

### 第 11 课：综合排错与复盘：从启动服务到定位问题

目标：把全部命令串成"启动 → 观察 → 诊断"的完整排查流程，并通过面试问答练习检验掌握程度。

内容：完整复盘"从启动一个 Python 程序到本地服务接受请求"每一步可用的命令（工作目录 → 环境 → 进程 → 端口 → 日志 → 退出码）；常见故障现象与定位路径（启动失败、端口占用、日志为空、Permission denied、磁盘满、服务无响应）；整理本课程面试高频题清单并模拟回答。

实践：编写一个最小 Python 服务并人为制造几类故障（错误路径、端口占用、无权限、日志未写），练习用第 2 至第 10 课的命令逐层定位。

面试考点：服务启动失败先看什么；接口连不上按什么顺序排查；如何回答"如何查询日志、如何查看最近的日志（反向排序）"。

## 学习方式

每一课先阅读概念，再执行命令；执行前预测命令输出，用实际结果校正自己的理解。命令练习应在安全的临时目录或明确指定的项目目录中完成；涉及文件变化时，课程会明确说明目标和副作用。进程操作只针对自己启动的课程进程，不操作系统进程；删除文件前先确认目标路径。

## 综合练习

完成"本地服务诊断"：启动一个最小 Python 服务（或让它启动失败），用工作目录、环境变量、进程、端口、日志和退出码逐层检查，最终给出"服务能启动/不能启动"的完整解释；并用 `tail`、`tac`、`grep` 从日志中提取最近的错误信息，用 `sort | uniq -c | sort -rn` 统计日志中各类错误的出现次数。

## 阶段验收

学习者应能够：

1. 解释 Linux、终端、Shell 和命令的关系，以及当前工作目录、绝对路径和相对路径。
2. 说明 `ls`、`find`、`rg`、`mkdir`、`mv`、`rm` 等命令的语法、参数和是否会修改文件。
3. 区分 stdout、stderr，说明重定向与管道的区别和用法。
4. 用 `head`、`tail`、`wc`、`sort`、`uniq`、`cut` 完成文本查看、排序和统计任务。
5. 回答"如何查询日志、如何查看最近的日志（反向排序）"，会用 `tail -f`、`grep`、`tac`、`journalctl -r` 并说明各自适用场景。
6. 解释权限位与数字权限，能定位并解决 Permission denied。
7. 解释环境变量、PATH、`which python` 与 `sys.executable` 的关系，并确认当前实际使用的 Python 环境。
8. 区分程序、进程和线程，说明 PID、退出码、信号和前后台的作用，能安全停止自己启动的进程。
9. 用 `ss`、`lsof`、`curl` 观察端口与本地服务，定位端口占用问题。
10. 用 `df`、`du`、`free`、`top` 观察系统资源，说明磁盘满、内存不足的排查思路。
11. 用自己的话完整回答"从启动 Python 程序到本地服务接受请求经历了哪些步骤"，以及"服务启动失败先看什么"。

## 课程编写约束

- **理论先行、实践在后**：先用文档讲清概念和机制，再动手执行；命令类课程以课程文档为主，配终端演示命令和验收问题，不编写代码作业；涉及运行 Python 脚本的课（第 8、11 课与综合练习）编写标准代码文件（课程示例 + 同文件作业）。
- 讲解要有逻辑、够详细：每个引入的命令都要说明它是什么、解决什么问题、输入输出和副作用；重要的工具值得单独成课（文本处理、日志、权限），不要一笔带过。
- 每课只引入少量新概念，先运行观察，再讲解原理；同一知识点不在多课重复展开。`grep`/`tail` 在第 4、5 课讲透，后续课程用到时一句话带过并引用。
- 在必要的地方使用 SVG 示意图辅助讲解（如终端/Shell/命令关系、三个标准流、权限位、进程生命周期），放在 `courses/engineering/linux/assets/` 下，以 `![说明](./assets/xxx.svg)` 引用；示意图沿用本仓库已有风格，避免整课全靠文字描述。
- 每课明确标注"面试高频考点"，但讲解从机制讲起，不直接给背诵结论。
- 文件操作练习只在安全的临时练习目录进行，避免对项目文件做无必要修改；进程操作只针对学习者自己启动的课程进程，不操作系统进程。
- 本课程只讲运行环境本身：网络（DNS、TCP/IP、HTTP、curl 报文细节）在阶段 3 的网络课程；部署相关（SSH、systemd 服务单元、tar 归档、容器）在阶段 10 展开。`journalctl` 只用于查看日志，不展开 systemd 服务管理。
- 每课使用通用、贴近真实工程的示例（启动服务、查看日志、排查接口问题等），不与具体项目强行关联。
