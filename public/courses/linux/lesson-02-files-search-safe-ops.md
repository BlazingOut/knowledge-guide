# 第二课：文件与目录：查找、复制与安全操作

本课学习创建、复制、移动和删除文件与目录的命令，以及两类查找命令：按位置查找的 `find` 和按内容搜索的 `rg`/`grep`。本课最重要的习惯是：先判断命令会不会修改文件，再执行；所有创建、修改和删除练习只在临时练习目录中进行。

## 1. 学习目标

完成本课后，你应当能够：

1. 用 `mkdir`、`touch` 创建目录和文件。
2. 用 `cp`、`mv`、`rm` 复制、移动和删除文件，并知道各自的副作用和风险。
3. 用 `find` 按位置查找文件，用 `rg`/`grep` 搜索文件内容。
4. 区分"搜索位置"和"搜索内容"两类查找，并在合适的场景选用。
5. 执行修改型命令前先确认目标路径，养成文件操作安全习惯。

## 2. 创建目录和文件：mkdir、touch

### 2.1 mkdir：创建目录

`mkdir` 创建目录。目录已存在时会报错，不会覆盖已有目录。

**常用形式**

```text
mkdir [选项] 目录路径
```

| 选项 | 含义 |
| --- | --- |
| `-p` | 需要的父目录不存在时一并创建；目录已存在时不报错。必会 |
| `-v` | 显示每个创建动作（了解即可） |

```bash
mkdir linux-course-tmp
mkdir -p linux-course-tmp/sub/deep
```

第二行会一次性创建 `linux-course-tmp`、`sub`、`deep` 三层目录。部署或搭项目结构时常用 `-p` 一次建好多级目录。

### 2.2 touch：创建空文件

`touch` 创建空文件；如果文件已经存在，则把它的修改时间更新为当前时间，不改变内容。

**常用形式**

```text
touch 文件路径
```

| 选项 | 含义 |
| --- | --- |
| （不带参数） | 文件不存在时创建空文件；已存在时更新修改时间。日常最常用 |

```bash
touch linux-course-tmp/notes.txt
touch linux-course-tmp/notes.txt   # 第二次执行只更新修改时间
```

可以用 `ls -l` 的修改时间列验证第二次 `touch` 的效果。

## 3. 复制、移动与删除：cp、mv、rm

### 3.1 cp：复制

`cp` 把来源复制到目标。复制目录必须加 `-r`，否则会报错。

**常用形式**

```text
cp [选项] 来源 目标
```

| 选项 | 含义 |
| --- | --- |
| `-r` | 递归复制目录及其全部内容；复制目录必须加 |
| `-i` | 目标已存在时，覆盖前先询问确认 |

```bash
cp linux-course-tmp/notes.txt linux-course-tmp/notes-backup.txt
cp -r linux-course-tmp linux-course-tmp-copy
```

### 3.2 mv：移动或重命名

`mv` 把来源移动到目标；当目标和来源在同一目录时，效果就是重命名。`mv` 不复制内容，因此比 `cp` 快，常用于归档文件。

**常用形式**

```text
mv [选项] 来源 目标
```

| 选项 | 含义 |
| --- | --- |
| （不带参数） | 把来源移动到目标位置，或重命名 |
| `-i` | 目标已存在时，覆盖前先询问确认 |

```bash
mv linux-course-tmp/notes-backup.txt linux-course-tmp/sub/   # 移动
mv linux-course-tmp/sub/notes-backup.txt linux-course-tmp/notes-final.txt   # 移动并重命名
```

注意：`mv` 覆盖已存在的目标文件同样不可恢复，需要覆盖时用 `-i` 确认。

### 3.3 rm：删除

`rm` 删除指定文件或目录。**Linux 没有回收站，删除不可恢复**；执行前必须确认目标路径。

**常用形式**

```text
rm [选项] 文件路径 ...
```

| 选项 | 含义 |
| --- | --- |
| `-r` | 递归删除目录及其全部内容；删除目录必须加 |
| `-f` | 强制删除，不询问、不显示错误 |
| `-i` | 删除前逐个询问确认 |

```bash
rm linux-course-tmp/notes.txt
rm -r linux-course-tmp-copy
```

`rm -rf` 是最危险的组合：`-r` 递归删掉整个目录树，`-f` 又不给任何确认机会，一旦执行无法恢复。绝不把 `rm -rf` 用在项目根目录、用户主目录或系统目录上。

## 4. 按位置查找：find

`find` 从起始目录开始递归查找，按条件匹配文件名、类型或深度。它回答的问题是"文件在哪里"。

**常用形式**

```text
find 起始目录 [条件 ...]
```

| 条件 | 含义 |
| --- | --- |
| `-name '模式'` | 按文件名匹配；引号让 `*` 等通配符原样传给 find，如 `'*.md'` 匹配所有 .md 结尾的文件 |
| `-type f` | 只匹配普通文件 |
| `-type d` | 只匹配目录 |
| `-maxdepth N` | 最多向下搜索 N 层，`1` 表示只看起始目录的直接内容 |

```bash
find courses -type f -name '*.md'
find courses/cs-basics -maxdepth 1 -type f
```

第一行递归找出 `courses` 下所有 Markdown 文件；第二行只看 `courses/cs-basics` 直接一层里的普通文件。

## 5. 按内容搜索：rg 和 grep

`rg`（ripgrep）是 `grep` 的现代替代品：更快、默认递归搜索目录、默认忽略 `.git` 等目录。选项与 `grep` 大体一致，面试和网上资料常说的 `grep`，本课的 `-n`、`-i`、`-l` 含义都相同。它回答的问题是"哪些文件包含这段内容"。

**常用形式**

```text
rg [选项] 搜索文字 [搜索路径]
```

不写搜索路径时，从当前目录递归搜索。

| 选项 | 含义 |
| --- | --- |
| `-n` | 显示匹配行所在的行号 |
| `-i` | 忽略英文大小写 |
| `-l` | 只列出包含匹配的文件名，不显示匹配内容 |

```bash
rg -n '面试考点' courses/cs-basics
rg -il 'linux' courses
```

第一行在计算机基础两门课的 README 里找"面试考点"并显示行号；第二行忽略大小写，只列出哪些文件提到了 "linux"。

## 6. 两类查找的分工与组合

| 命令 | 回答的问题 | 查找对象 |
| --- | --- | --- |
| `find` | 文件在哪里 | 文件名、类型、目录层级 |
| `rg`/`grep` | 哪些文件包含这段内容 | 文件内容 |

两者经常组合使用：先用 `find` 圈定文件范围，再用 `rg` 在内容里搜索。下面的组合先找出所有 Markdown 文件，再从结果里筛选路径包含 `lesson` 的行（管道 `|` 在第 3 课详解，这里先记住它的作用）：

```bash
find courses -name '*.md' | rg 'lesson'
```

排查"找不到文件/找不到内容"时，这个分工很实用：文件不在预期位置用 `find`，文件在但内容搜不到用 `rg`，权限问题会在第 6 课展开。

## 7. 文件操作安全习惯

1. 创建、修改、删除练习只在临时练习目录进行，不在项目目录、主目录或系统目录实验；
2. 执行修改型命令前，先 `pwd` 确认当前目录、`ls` 确认目标路径；
3. 删除和覆盖没有回收站，需要确认时用 `-i`，不确定时先不执行；
4. `rm -rf` 只在明确知道要清理整个临时目录时使用，绝不用于项目或系统路径。

## 8. 在真实工程中的对应场景

1. `mkdir -p` 一次性搭好多级目录结构（如部署目录、日志目录）；
2. `touch` 创建空的配置文件或 `.gitkeep` 占位文件；
3. `cp -r` 复制整个目录做备份，再改副本而不动原件；
4. `mv` 重命名文件、把旧版本移到归档目录；
5. 清理临时文件或过期日志前，先 `ls` 确认要删的是什么；
6. `find` 定位某个配置文件、日志文件在系统或项目中的位置；
7. `rg` 在代码库里搜索函数名、报错关键词、配置项；
8. 报错说"文件不存在"时，先用 `find` 确认文件是否存在，再检查路径和权限。

## 9. 运行本课命令练习

练习目录统一放在用户主目录下的临时目录 `~/linux-course-tmp`，全部练习结束后确认内容再删除整个目录：

```bash
mkdir -p ~/linux-course-tmp/sub/deep
touch ~/linux-course-tmp/notes.txt
cp ~/linux-course-tmp/notes.txt ~/linux-course-tmp/notes-backup.txt
cp -r ~/linux-course-tmp ~/linux-course-tmp-copy
mv ~/linux-course-tmp/notes-backup.txt ~/linux-course-tmp/sub/
find ~/linux-course-tmp -type f
find courses -type f -name '*.md'
rg -n 'linux' courses/engineering/linux
```

最后确认无误后删除练习目录：

```bash
ls -R ~/linux-course-tmp
rm -r ~/linux-course-tmp ~/linux-course-tmp-copy
```

每执行一条修改型命令前，先预测它对文件系统做了什么（创建了什么、覆盖了什么、删了什么），再观察实际结果。

## 12. 面试考点

- **find 和 grep 的区别**：`find` 按文件名、类型和位置查找；`grep`/`rg` 按文件内容搜索；实际排查中经常用管道组合：`find 目录 -name '*.log' | grep 'ERROR'`。
- **rm -rf 为什么危险**：`-r` 递归删除目录树，`-f` 强制不询问，合起来会静默删除整个目录且无法恢复（Linux 没有回收站）。
- **如何找到一个文件或一段内容**：找文件用 `find 起始目录 -name '模式'`；找内容用 `rg -n '关键词' 路径` 或 `grep -rn '关键词' 路径`（传统 grep 搜索目录要加 `-r`）。
- **哪些命令会修改文件**：`mkdir`、`touch`、`cp`、`mv`、`rm` 以及重定向 `>`（第 3 课）；只读观察的是 `ls`、`find`、`rg`/`grep`、`cat` 等。执行修改型命令前先确认目标和副作用。

## 13. 本课小结

创建、复制、移动和删除文件的命令都会改变文件系统，执行前必须确认目标路径和副作用；查找命令分两类：`find` 按位置找文件，`rg`/`grep` 按内容找文本，两者分工互补。所有练习遵循"临时目录 + 先确认再修改"的安全习惯。
