# 第一课：Linux、终端、Shell 与命令基础

本课建立使用 Linux 和终端观察项目的基本方法。你不需要编写新的 Python 程序，也不需要记住所有命令；本课的目标是能够回答：我现在在哪里？项目文件在哪里？我执行的命令到底是做什么的？

## 1. 学习目标

完成本课后，你应当能够：

1. 区分 Linux、终端、Shell 和命令。
2. 阅读一条命令的结构：命令名、选项、参数。
3. 区分只观察状态的命令和会修改文件的命令。
4. 解释当前工作目录、绝对路径和相对路径，以及 `.` 和 `..` 的含义。
5. 使用 `pwd`、`cd`、`ls` 观察和切换位置。
6. 说出常用系统目录（`/`、`/home`、`/etc`、`/var/log`、`/tmp`）的用途。
7. 知道如何在 Windows 上安装并进入 WSL2 的 Linux 环境（本课命令在 WSL2 终端中执行）。

## 2. Linux、终端、Shell 和命令

### 2.1 Linux 是什么

Linux 是一种操作系统环境，负责管理文件、进程、内存、设备和网络等资源。本阶段只使用 Linux 提供的命令行工具观察和运行程序，不深入学习内核实现。

### 2.2 终端和 Shell 是什么

终端是输入命令、查看输出的交互界面。Shell 是运行在终端中的命令解释器：它读取文字命令，找到对应程序并启动它。常见的 Shell 有 bash 和 zsh。

可以用下面的关系理解：

~~~text
终端窗口
    -> Shell
        -> 解释命令
            -> 启动程序
                -> 显示输出或错误
~~~

终端不是 Linux 本身，Shell 也不是 Python。输入 `python --version` 时，Shell 会找到 Python 可执行程序并启动它；Python 输出版本信息后结束，Shell 再次等待输入。

### 2.3 如何阅读一条命令

一条命令通常由命令名、选项和参数组成：

```text
命令名 [选项] [参数 ...]
```

方括号表示这一部分可以省略，不是要原样输入。各部分的作用：

| 部分 | 作用 | 示例 |
| --- | --- | --- |
| 命令名 | 决定运行哪个程序 | `ls` |
| 选项 | 以 `-` 或 `--` 开头，改变命令行为 | `-l`、`--all` |
| 参数 | 告诉命令处理什么对象 | `courses` |

例如 `ls -la courses`：命令名是 `ls`，选项是 `-l` 和 `-a` 的合写，参数是 `courses`。多个短选项可以合写在一个 `-` 后（`-la` 等价于 `-l -a`），但不是所有选项都能这样合并。

理解一条命令还要知道三件事：它接收什么输入、输出什么、会不会修改文件。这正是下一节的内容。

### 2.4 命令的输入、输出与副作用

按是否修改文件，命令可以分为两类：

| 类型 | 特点 | 常见例子 |
| --- | --- | --- |
| 观察型命令 | 只读取文件和状态，不改变任何内容 | `pwd`、`ls`、`cat`、`find`、`rg` |
| 修改型命令 | 会创建、覆盖、移动或删除文件 | `mkdir`、`mv`、`rm` |

`cat`、`find`、`rg` 和文件操作命令的详细用法在后面的课程展开，本课先建立"执行命令前先判断它是否会修改文件"的习惯。特别是删除类命令，执行前要确认目标路径。

## 3. 在 Windows 上使用 WSL2 操作 Linux

本课程的命令需要在 Linux 环境里执行。如果你使用的是 Windows，可以通过 WSL2（Windows Subsystem for Linux，适用于 Linux 的 Windows 子系统）在 Windows 里运行一个完整的 Linux 发行版（如 Ubuntu）。本课及后续课程的终端命令都在 WSL2 的 Linux 终端中执行。

**安装与进入**

- 安装：在管理员 PowerShell 中执行 `wsl --install`，按提示重启并完成 Ubuntu 的用户名和密码设置即可（详细步骤以微软官方文档为准，本课不展开）。
- 进入：开始菜单打开 Ubuntu 应用，或在 Windows Terminal / PowerShell 中执行 `wsl` 回车，就进入了 Linux 终端。
- 验证：执行 `pwd`、`ls /`、`uname -a`，能正常输出即说明 Linux 环境就绪。

**文件系统**

WSL 里的 Linux 与 Windows 共用一台电脑，但目录体系是分开的：

| 位置 | 含义 |
| --- | --- |
| `/mnt/c/` | Windows 的 C 盘在 WSL 中挂载在这里，如 `/mnt/c/Users/you` |
| `\\wsl$\Ubuntu\...` | 在 Windows 资源管理器中访问 WSL 内部文件的路径（了解即可） |

练习建议放在 WSL 自己的文件系统（如 `/home/you`）中；需要与 Windows 交换的文件放在 `/mnt/c/` 下，两边都能访问。终端推荐使用 Windows Terminal 或 VSCode 的 WSL 集成终端。

## 4. 当前工作目录与路径

### 4.1 当前工作目录

当前工作目录（current working directory，CWD）是命令或程序启动时默认使用的目录。命令和相对路径都从它开始解析。

使用 `pwd` 查看：

**常用形式**

```text
pwd [选项]
```

日常使用不携带任何参数；`-P` 只在与符号链接相关的场景用到，了解即可。

| 选项 | 含义 |
| --- | --- |
| （不带参数） | 显示当前工作目录的绝对路径，日常最常用 |
| `-P` | 显示物理路径，忽略符号链接（了解即可） |

```bash
pwd
```

如果输出为：

```text
/home/you/projects/ai-study
```

那么 `courses/cs-basics/network/README.md` 就会从 `/home/you/projects/ai-study` 开始查找。换到其他目录后，同一条相对路径可能指向另一个文件，或者根本不存在。

### 4.2 绝对路径和相对路径

绝对路径从文件系统根目录 `/` 开始，可以独立描述位置：

```text
/home/you/projects/ai-study/courses/cs-basics/network/README.md
```

相对路径从当前工作目录开始描述位置：

```text
courses/cs-basics/network/README.md
```

`.` 表示当前目录，`..` 表示当前目录的父目录。路径只是告诉操作系统去哪里找，不是文件内容，也不是文件对象。

### 4.3 切换目录：cd

`cd` 是 change directory 的缩写，只改变当前 Shell 的目录状态，不会移动或修改文件。

**常用形式**

```text
cd [目录路径]
```

`cd` 接收目录路径而不是选项，常用写法如下：

| 写法 | 含义 |
| --- | --- |
| `cd` | 回到当前用户的主目录 |
| `cd ~` | 同上，`~` 表示主目录 |
| `cd ..` | 进入当前目录的父目录 |
| `cd -` | 回到上一次所在的目录 |
| `cd courses` | 进入当前目录下的 `courses`（相对路径） |
| `cd /etc` | 进入绝对路径 `/etc` |

```bash
cd courses
pwd
cd ..
pwd
cd -
pwd
```

## 5. 文件系统目录层次

Linux 文件系统从根目录 `/` 开始，是一棵目录树。常见目录的用途：

| 目录 | 用途 |
| --- | --- |
| `/` | 文件系统根目录，所有路径从这里开始 |
| `/home` | 普通用户的主目录（如 `/home/you`） |
| `/etc` | 系统和服务的配置文件 |
| `/var/log` | 系统和服务的日志文件（第 5 课会详细用到） |
| `/tmp` | 临时文件目录，重启后可能被清理 |
| `/usr` | 系统程序和库（了解即可） |

本课程的命令练习在项目目录和临时目录中进行，不修改 `/etc`、`/usr` 等系统目录。

## 6. 观察文件和目录：ls

`ls` 列出目录内容，只读取目录，不修改文件。

**常用形式**

```text
ls [选项] [目录路径]
```

不写目录路径时，默认查看当前工作目录；目录参数可以写相对路径或绝对路径。

常用选项：

| 选项 | 含义 |
| --- | --- |
| `-l` | 详细格式：权限、所有者、大小、修改时间 |
| `-a` | 显示所有文件，包括以 `.` 开头的隐藏文件 |
| `-h` | 与 `-l` 搭配，把大小显示为 K/M/G 等人性化单位 |
| `-t` | 按修改时间排序，最新的在前（第 5 课找最新日志会用到） |

```bash
ls
ls courses
ls -la
ls -lh
ls -lt courses
```

`-la` 是 `-l -a` 的合写形式；`ls -la` 等价于 `ls -l -a`。

## 7. 在真实工程中的对应场景

本课程的命令会在日常开发中反复出现，提前建立这些习惯：

1. 登录服务器或打开终端后，先 `pwd` 确认自己在哪个目录；
2. 用 `ls` 查看项目目录、日志目录里有什么，`ls -lt` 按时间看最新的文件；
3. 用 `cd` 在项目目录之间切换，`cd -` 快速回到刚才的位置；
4. 执行修改型命令（尤其是删除）前，先确认目标路径和当前工作目录；
5. 遇到"文件明明存在但程序找不到"的问题，先检查路径是相对哪个目录解析的。

## 8. 运行本课命令练习

命令默认在项目根目录执行。如果你使用 Windows，请先按第 3 节进入 WSL2 的 Linux 终端，再执行下面的命令：

```bash
pwd
ls
ls -la
ls -lh
cd courses
pwd
cd ..
pwd
cd -
```

每条命令执行后，记录命令名、选项、参数、输出，以及它属于观察型还是修改型。本课出现的 `pwd`、`ls`、`cd` 都是观察型命令，不会修改文件。

## 11. 本课小结

Shell 在当前工作目录中启动命令；命令通过选项和参数控制行为，通过路径找到文件。当前工作目录决定相对路径解析到哪里，绝对路径则不依赖任何目录。

下一课将在这个基础上学习文件与目录的操作命令（`mkdir`、`touch`、`cp`、`mv`、`rm`），以及如何用 `find` 和 `rg` 查找文件与内容。
