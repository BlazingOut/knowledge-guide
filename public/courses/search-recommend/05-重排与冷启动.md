# 第5课:重排与冷启动

第 4 课的离线指标合格，只说明模型拿到了上线资格。线上给司机看的最终名单，还不是精排分数直接排出来的那一份：同一司机不该连续看到互相冲突的货，新司机新货一条都没露过面就永远没有数据。这些事精排的分数管不了，由重排和冷启动策略接管。

本课讲三类内容：重排规则改什么、冷启动靠什么、成交之后的数据怎么流回来。不引入新的模型，全部是规则和约束。

**学习目标：**

1. 说明精排分数为什么不是最终顺序，重排在哪一段起作用；
2. 列出四类常见重排规则，说出每条规则保护了什么、伤害了什么；
3. 说明新司机、新货、新线路上为什么复杂模型不可靠，冷启动退回什么、探索什么；
4. 分清曝光、点击、成交、取消、履约五种事件各记什么，取消率高的“高成交预测”坏在哪；
5. 说出价格、补贴、风控、大模型助手在链路里各自的边界。

## 1. 精排分数不是最终顺序

精排输出的是“这个司机看到这票货、发生成交的可能性”。它只回答一件事：单看这条候选，好还是不好。但一页名单是**一组**候选，组内还有精排没有管的关系：

```text
精排分数（只看单条）        一页名单（要看成组）
货 A 0.91                  A 和 B 是同一条货的两个报价 -> 重复
货 B 0.88                  C 和 D 同一天同一区间 -> 冲突
货 C 0.85                  新货 E 没有任何历史 -> 分数没有依据
货 D 0.80
货 E 0.30
```

这些关系在特征里放不下：第 3 课讲过，逻辑回归只做加权和，“和 B 同时出现”这种页内关系不是单条样本的特征；树模型同样只看单条的列。于是链路在精排之后加一段**重排**：输入是精排的有序名单，输出是调整后的名单，用的是规则和简单约束，不是再训练一个大模型。

## 2. 重排规则：保护什么，伤害什么

四类最常见的规则。每条规则都在修正分数的一个盲区，同时都在**伤害纯分数序**——这个代价要当场说出来。

**互斥去重。** 同一司机同一天只能执行一单，两条货装货时间重叠、区间相近，接了甲就必然放弃乙。把两条都排在前排是在制造必然的流失。规则：同区间冲突的货只保留分数最高的一条。伤害：被挤掉的那条分数更高，名单的“平均分”下降。

**相似去重。** 同一条货的多个报价、同一线路只差一小时的两条货，司机看来是同一条。规则：按货的实体（线路 + 车型 + 时间段）聚簇，每簇只展示一两条。伤害：可能压掉了簇内分数更高的报价。

**保曝光。** 新货、新线路没有成交记录，精排给不出有依据的分数，永远排不进前排，也就永远没有数据。规则：给新实体保留固定的最低曝光位（比如每页至少一条）。伤害：占据前排的位置，挤掉一条分数更高的老货。

**亏损过滤。** 某些货的价格明显低于线路成本，成交了也是亏本单，或大概率被司机秒拒。规则：直接过滤或降权，不交给模型“学习掉”——第 2 课讲硬过滤时说过同一原则：明确知道是错的，不留给模型。伤害：几乎为零，除非“看起来亏”的判断本身错了。

重排规则的共同写法：**先说清保护什么，再说清伤害什么。** 说不清伤害的规则是危险的，因为它悄悄改变了优化目标却没有人知道。

## 3. 冷启动：没有历史时退回规则

**冷启动**指新实体没有足够历史数据：新司机没有接单记录，新货没有成交记录，新线路两边都新。第 2 课讲过协同过滤在冷启动上失效——它的一切依据是“过去相似的人做了什么”，过去是空白时无相似可找。第 3 课的复杂模型同理：行为序列是空的，输入向量里大半是默认值。

冷启动不是一个算法，是一组退路加一段探索：

1. **退回规则分。** 新司机用注册信息（车型、常驻城市）匹配硬过滤后的货，按距离和价格这些不依赖历史的属性排序；新货同理用线路、车型、价格定位到“和它相似的旧货”的人群。这些列在第 3 课的特征表里都出现过，只是这时它们是仅有的几列。
2. **用探索换数据。** 给新实体保留最低曝光（第 2 节的保曝光规则），让它们有机会被点击、成交，历史从此开始积累。探索的量要控制：给一个完全没有依据的新货大量曝光，是用真实流量赌运气。
3. **新线路整条链路退回。** 没有历史成交价、没有运力统计时，报价区间和预期时长都先用固定规则给出，同时把这条线路标记为“数据不足”，特征里对应的列显式置成缺失而不是填 0——填 0 是一个假值，缺失才是真话。

判断一段冷启动方案是否算“做了”：它有没有说出**数据从哪里开始积累、多少曝光后切换到正常排序**。只说“用内容特征做推荐”而不说探索和数据回流，等于没做。

## 4. 反馈闭环：五种事件分开记

名单展示出去之后，每一环都要记下来，而且**分开记**：

| 事件 | 记什么 | 说明什么 |
| --- | --- | --- |
| 曝光 | 货出现在司机屏幕上 | 排序真实生效了，是一切后续的前提 |
| 点击 | 司机打开详情 | 有兴趣，还不确定 |
| 成交 | 司机接受匹配 | 交易达成 |
| 取消 | 成交后司机或货主撤销 | 达成是假的，匹配错了 |
| 履约 | 按约定完成运输 | 最终交付 |

第 3 课把标签分成点击、成交、履约三档，这里多了取消。取消是成交之后的坏结局：一条货“成交率高但取消也高”，说明匹配在当时说得通、执行时发现不行——时间窗没对上、车型不符的细节、价格谈崩。把这样的成交当正样本，模型学到的是“容易骗到接受”的货。成交要等取消窗口过去才能确认，这就是第 3 课说的标签延迟在反馈闭环里的样子。

反馈闭环还决定第 4 课的评估能不能做：没有分开记录的事件流，就没有带正确标签的测试集。排序系统的问题排查也沿着这条链走——曝光了没点击查排序和价格，点击了没成交查详情页信息，成交了总取消查约束校验。

## 5. 价格与相邻系统的边界

价格在链路里出现两次：它是货的一个特征列（第 3 课），也是成交概率的输入——同样的货，价格高成交可能性低。精排分数因此可以读成“**这个价格下，成交且能履约的可能性**”。改价格就会改分数，但改价格不是排序模块的事。

三个相邻系统各留一句边界：

- **补贴**改变价格特征，从而间接改变分数；它由运营和策略系统决定，排序只接收结果。
- **风控**负责剔除异常样本和异常账户（刷单、虚假货源）；它发生在样本进入训练之前，排序不处理。
- **大模型助手**可以用来生成推荐理由、解释为什么推这条货；解释是展示层的事，不参与打分。

这三者都不替代召回和排序。被问到时，先说清自己负责的段落，再一句带过相邻系统——越界展开是面试减分项。

## 6. 动手：给 5 条结果做重排

精排已按分数排好 5 条，司机是一名新司机（注册 3 天，无成交记录）：

```text
货 A 0.91  北京->天津  箱式  明早装货   老货
货 B 0.88  北京->天津  箱式  明早装货   老货   （与 A 同实体：同线路同车型同时段）
货 C 0.85  北京->天津  箱式  明早装货   老货   （与 A、B 同实体）
货 D 0.80  北京->廊坊  高栏  明早装货   新货   （首条发布）
货 E 0.60  天津->济南  厢式  后天装货   老货
```

套两条规则：**同实体去重**（同线路同车型同装货时段只留一条）；**新货保曝光**（新货至少一条进入前 3）。

重排过程：A、B、C 同实体，保留分数最高的 A，B、C 移出名单；D 是新货但排在第 4 位，不满足保曝光，与 E 交换位置，E 移到第 4。最终名单：A、D、E。加上召回候选外无替代时，名单变短是正常现象，凑数不如留白。

伤害了纯分数的地方有两处：B（0.88）和 C（0.85）被去重规则挤掉，虽然它们的分数高于保留下的 D（0.80）；E（0.60）因保曝光规则升到第 2 位，压过了没有上位资格的问题——它是被位置奖励的，不是被分数奖励的。两条规则各自保护了“司机不看到重复”和“新货有起点”，代价都记在分数上。

## 7. 验收问题

1. 精排分数为什么不直接作为展示顺序？举出两个页内存在、单条特征里放不下的关系。
2. 四类重排规则各自保护什么、伤害什么？为什么“说不清伤害的规则是危险的”？
3. 新线路为什么协同过滤和复杂模型都不可靠？冷启动的退路是什么、数据从哪里开始积累？
4. 取消为什么必须和成交分开记？把取消多的成交当正样本，模型会偏向什么货？
5. 价格、补贴、风控、大模型助手，谁在改分数、谁不参与打分？

## 8. 面试高频考点

**为什么有了精排还要重排。** 精排只对单条候选打分，管不了页内关系：同实体重复、互斥冲突、新实体保曝光、明确亏损单，这些是业务规则不是统计规律，也不可能是单条样本的特征。重排用规则和约束对精排名单做最后一道修改，每条规则都要能说出保护了什么、伤害了什么。

**冷启动怎么做才不是空话。** 新实体没有历史，协同过滤和行为序列模型都无从下手。做法分三层：退回不依赖历史的属性（线路、车型、价格）排序；用受控的最低曝光做探索，让数据开始积累；明确“多少曝光、多少反馈后切回正常排序”。只说“用内容特征”而不说数据回流，是没做完。

**哪些约束必须硬编码。** 明确知道对错的规则不交给模型：车型载重的硬条件（第 2 课）、互斥时间去重、亏损过滤。模型学的是“倾向”，不是“对错”；把硬约束交给模型，等于允许它偶尔输出违法物理和规则的名单。

**结果不好先查哪。** 沿反馈闭环从前往后：曝光了没有（召回覆盖、保曝光规则）→ 曝光了没点击（排序头部、价格）→ 点击了没成交（详情信息与实际约束）→ 成交了取消率高（约束校验、标签延迟）。一次只改一个怀疑点，改完对照业务指标。

**下一课预告：** 前五课的段落都齐了。第 6 课把它们串成一条固定叙事——从一笔“北京到天津、9.6 米、明早装货”的货进请求，讲到“为什么把这三名司机排在前面”，并用一段综合练习代码把硬过滤、召回、打分、重排、精确率一次跑通。
