# Python 工程化

本课程面向能够阅读和编写基础 Python，但希望系统补齐工程 Python 知识的学习者。课程从异常处理开始，逐步进入文件、数据建模、模块与包、Python 语言工具、工程实践，以及进入 FastAPI 和 Redis 课程前所需的异步基础。

## 课程目录

### 第一课：异常与错误处理

- 异常产生、传播和处理；`try`、`except`、`else`、`finally`；
- 内置异常、自定义异常、异常边界和异常链；
- 何时处理、何时继续抛出；
- 异常路径的函数设计和测试。

练习：为生活记录操作增加输入错误、资源不存在和业务规则异常。
文件：[`01-异常与错误处理.md`](<01-异常与错误处理.md>)

### 第二课：文件、路径和数据转换

- 文件读写、`pathlib`、编码和换行；
- JSON 序列化与反序列化；
- 数据结构与文件格式转换；
- 字段缺失、错误类型和格式版本；
- `with` 管理文件资源；
- 文件持久化边界。

练习：实现生活记录 JSON 加载与保存。
文件：[`02-文件、路径和数据转换.md`](<02-文件、路径和数据转换.md>)

### 第三课：类、数据建模和类型标注

- 类、实例、属性、方法和对象状态；
- 继承、组合和协议；
- `dataclass`、枚举和领域模型；
- 类型标注、可选值、集合类型和返回值；
- 类型标注与运行时校验的区别。

练习：把生活记录从字典改造成带类型的数据模型，并设计简单的存储接口。
文件：`03-类、数据建模和类型标注.md`

### 第四课：模块、包与项目结构

- 模块和 `import`；绝对导入与相对导入；
- `__name__ == "__main__"`；直接运行文件和 `python -m`；
- 包目录、项目入口和导入错误；
- 从单文件脚本拆分模型、服务、存储和入口。

练习：把生活记录程序拆成一个小型 Python 包。
文件：`04-模块、包与项目结构.md`

### 第五课：迭代器、生成器、上下文管理器

- 可迭代对象、迭代器、`iter`、`next` 和 `StopIteration`；
- 迭代器协议：`__iter__`、`__next__` 和自定义迭代器；
- 生成器函数、`yield` 和惰性求值；
- 生成器在逐条读取记录中的应用，以及提前停止和只迭代一次；
- 上下文管理器、`with`、`__enter__`、`__exit__` 和资源清理；
- `__exit__` 的返回值和异常传播；
- `contextlib.contextmanager` 简化写法；
- 在实际库和框架中识别这些机制。

练习：实现逐条读取记录的生成器、计时上下文管理器，以及记录学习耗时的上下文管理器。
文件：`05-迭代器、生成器、上下文管理器.md`

### 第六课：装饰器

- 函数是对象：赋值、作为参数和返回值；
- 装饰器、`@` 语法糖和函数包装；
- `functools.wraps` 保留函数元信息；
- 带参数的装饰器（装饰器工厂）和有状态的装饰器；
- 装饰器的常见用途：日志、计时、重试、权限和缓存；
- 在实际库和框架中识别装饰器（`@dataclass`、FastAPI 路由、pytest fixture）。

练习：为提醒服务实现统计调用次数的装饰器，并实现带重试次数的失败重试装饰器。
文件：`06-装饰器.md`

### 第七课：工程 Python

- `logging`、配置与环境变量；
- 命令行参数和程序入口；
- pytest、fixture、单元测试、集成测试和 mock；
- traceback、断点、最小复现、代码质量和重构。

练习：完成可运行、可测试的命令行生活记录应用。
文件：`07-工程 Python.md`

### 第八课：Python 异步基础与并发 IO

- 同步、异步、并发和并行的区别；
- 阻塞与非阻塞，以及异步主要适合等待 I/O 的原因；
- `async def`、协程对象、`await` 和 `asyncio.run()`；
- 事件循环的直观模型，以及协作式让出执行权；
- `asyncio.create_task()`、`asyncio.gather()` 和多个 I/O 操作的并发等待；
- 异步任务的异常、超时、取消和 `finally` 清理；
- `time.sleep()` 等同步阻塞调用对事件循环的影响；
- 使用 `asyncio.to_thread()` 处理必要的阻塞调用，并理解它不等于 CPU 并行；
- 区分 Python 协程、后台任务和消息队列，避免把这些概念混为一谈。

本课只建立能够支撑后续 FastAPI 和 Redis 学习的运行模型，不深入事件循环源码、操作系统 I/O 多路复用、复杂线程同步或消息队列实现。

练习：使用 `asyncio.sleep()` 模拟多个独立的网络操作，比较逐个等待和并发等待的耗时；增加一个失败或超时任务，并保证任务结束后能够清理资源。

验收：能够解释为什么调用协程函数不会立即得到最终结果，为什么连续 `await` 不等于并发，为什么阻塞调用会影响同一事件循环中的其他任务，以及任务失败或取消后如何进行清理。
文件：`08-Python 异步基础与并发 IO.md`

## 课程目标

完成后，你应当能够编写一个包含数据模型、内存存储、JSON 持久化、命令行入口、日志和测试的小型 Python 应用，能够读写和编写基本异步代码，并具备继续学习 FastAPI 异步接口、模型调用和 Redis 异步任务的基础。
