# 堆
## 第一部分：核心思想与定义

### 1. 一句话定义

堆（Heap）是一种基于**完全二叉树**实现的特殊数据结构，它能够在 $O(1)$ 时间内获取当前的最小值或最大值，并在 $O(\log n)$ 时间内完成插入和删除堆顶元素。

堆通常通过数组实现，不需要显式创建树节点。Python 中的 `heapq` 模块提供了**最小堆**实现。

### 2. 核心概念

#### 完全二叉树

堆必须是一棵完全二叉树：除了最后一层外，每一层都必须填满，并且最后一层的节点从左到右连续排列。

这种结构可以直接使用数组保存：

```text
          1
        /   \
       3     2
      / \   /
     7   5 4

数组表示：[1, 3, 2, 7, 5, 4]
```

对于下标为 `i` 的节点：

- 左子节点下标：`2 * i + 1`
- 右子节点下标：`2 * i + 2`
- 父节点下标：`(i - 1) // 2`

#### 堆序性质

- **小根堆（最小堆）**：父节点的值小于或等于子节点的值，堆顶是全局最小值。
- **大根堆（最大堆）**：父节点的值大于或等于子节点的值，堆顶是全局最大值。

需要注意：堆只保证父子之间的大小关系，并不保证整个数组有序。因此，堆不是排序数组，不能通过下标直接得到所有元素的有序顺序。

### 3. 堆的基本操作与复杂度

| 操作 | 说明 | 时间复杂度 |
| :--- | :--- | :--- |
| 获取堆顶 | 查看最小值或最大值 | $O(1)$ |
| 插入元素 | 放到末尾后向上调整 | $O(\log n)$ |
| 删除堆顶 | 用末尾元素替换堆顶后向下调整 | $O(\log n)$ |
| 建堆 | 将数组调整为堆 | $O(n)$ |
| 查找任意元素 | 堆不支持高效查找任意值 | $O(n)$ |

### 4. 为什么堆能高效维护极值

堆把当前最小值或最大值固定在根节点，也就是数组的第一个位置。每次插入或删除后，只需要沿着一条从叶子到根或从根到叶子的路径调整，路径长度最多是树高 $O(\log n)$，因此可以高效维护堆顶元素。

## 第二部分：适用场景与问题识别

### 1. 问题特征信号

看到下面这些关键词时，应优先考虑堆或优先队列：

- **第 K 大 / 第 K 小**；
- **前 K 个最大值或最小值**；
- **持续加入数据，同时查询当前最小值或最大值**；
- **每次选择当前最小或最大的任务处理**；
- **合并多个有序序列**；
- **中位数、实时排名、动态数据流**；
- **按照优先级处理元素**。

### 2. 典型适用场景

#### Top K 问题

例如求数组中第 `k` 大的元素。维护一个大小为 `k` 的小根堆：

- 堆中保存当前最大的 `k` 个元素；
- 堆顶是这 `k` 个元素中最小的一个；
- 新元素比堆顶大时，替换堆顶；
- 最后堆顶就是第 `k` 大的元素。

#### 优先队列

普通队列按照进入顺序处理任务，优先队列按照优先级处理任务。每次都需要取出当前最小或最大元素时，堆可以避免每次重新排序。

#### 合并有序数据

合并多个有序链表或有序数组时，可以把每个序列当前的最小元素放入小根堆，每次取出最小值，再将该元素所在序列的下一个元素放入堆中。

#### 图算法

Dijkstra 最短路径算法、Prim 最小生成树算法都需要反复选取当前距离最小或边权最小的节点，通常使用优先队列实现。

#### 数据流问题

求数据流中的中位数时，可以使用一个大根堆保存较小的一半元素，再使用一个小根堆保存较大的一半元素。

### 3. 堆与其他数据结构的区别

| 数据结构 | 适合场景 | 获取极值 | 插入元素 |
| :--- | :--- | :--- | :--- |
| 无序数组 | 普通存储 | $O(n)$ | $O(1)$ |
| 有序数组 | 二分查找、顺序访问 | $O(1)$ | 通常为 $O(n)$ |
| 堆 | 动态维护极值 | $O(1)$ | $O(\log n)$ |
| 平衡搜索树 | 有序查询、范围查询 | $O(\log n)$ | $O(\log n)$ |

堆的优势是动态维护极值，而不是支持任意位置的快速查找或完整有序遍历。

## 第三部分：标准化解法模板

### 1. Python 最小堆基础操作

Python 的 `heapq` 默认是小根堆。

```python
import heapq

heap = []

# 入堆
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)

# 查看堆顶，不删除
top = heap[0]  # 1

# 删除并返回堆顶
value = heapq.heappop(heap)  # 1

# 判断是否为空
is_empty = not heap
```

### 2. 从数组建堆

使用 `heapify` 可以在线性时间内将数组原地转换为小根堆：

```python
import heapq

nums = [5, 2, 8, 1, 3]
heapq.heapify(nums)

smallest = heapq.heappop(nums)
```

`heapify` 后只能保证 `nums[0]` 是最小值，不能认为整个 `nums` 已经升序排列。

### 3. 模拟大根堆

Python 没有直接提供大根堆，可以把元素取相反数后放入小根堆：

```python
import heapq

heap = []
for value in [3, 1, 5, 2]:
    heapq.heappush(heap, -value)

maximum = -heapq.heappop(heap)  # 5
```

如果堆中保存的是元组，也可以把排序字段取负：

```python
heapq.heappush(heap, (-priority, task))
```

### 4. Top K 模板：第 K 大元素

维护一个大小不超过 `k` 的小根堆：

```python
import heapq


def kth_largest(nums: list[int], k: int) -> int:
    heap = []

    for value in nums:
        heapq.heappush(heap, value)
        if len(heap) > k:
            heapq.heappop(heap)

    return heap[0]
```

堆中始终保留当前最大的 `k` 个元素，堆顶是其中最小的元素，也就是第 `k` 大的元素。

时间复杂度为 $O(n\log k)$，空间复杂度为 $O(k)$。

### 5. 优先队列模板

使用元组时，`heapq` 默认按照元组的第一个元素排序：

```python
import heapq

tasks = []
heapq.heappush(tasks, (2, "普通任务"))
heapq.heappush(tasks, (1, "紧急任务"))

priority, task = heapq.heappop(tasks)
```

如果多个任务优先级相同，可以增加一个递增编号，避免任务对象本身无法比较：

```python
import heapq
from itertools import count

counter = count()
heap = []

heapq.heappush(heap, (1, next(counter), "task-A"))
heapq.heappush(heap, (1, next(counter), "task-B"))

priority, _, task = heapq.heappop(heap)
```

### 6. 边界条件与常见陷阱

- **空堆调用 `heappop`**：会抛出 `IndexError`，操作前先判断堆是否为空。
- **误以为堆数组有序**：堆只保证堆顶和父子关系，不保证数组整体有序。
- **大根堆忘记取负**：插入和取出时都要保持相反数逻辑。
- **Top K 堆大小不受控**：如果维护第 `k` 大元素，堆大小必须限制为 `k`，否则空间复杂度会变成 $O(n)$。
- **元组排序规则不清楚**：元组先比较第一个元素，第一个相同才比较第二个元素。
- **重复元素**：默认可以正常保留重复值；如果题目要求去重，需要额外使用集合或根据题意处理。

## 第四部分：精选题目与学习路径

### 核心母题

1. **[LeetCode #215 数组中的第 K 个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)**
   
   - **为什么选此题**：Top K 问题的经典代表，掌握大小为 `k` 的小根堆。
   - **核心思路**：遍历数组并维护一个最多包含 `k` 个元素的小根堆。
   - **复杂度**：时间 $O(n\log k)$，空间 $O(k)$。

2. **[LeetCode #703 数据流中的第 K 大元素](https://leetcode.cn/problems/kth-largest-element-in-a-stream/)**
   
   - **为什么选此题**：练习数据不断加入时如何动态维护第 K 大元素。
   - **核心思路**：始终维护一个大小为 `k` 的小根堆。
   - **复杂度**：每次添加元素的时间复杂度为 $O(\log k)$。

### 变式进阶

1. **[LeetCode #347 前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)**：哈希表统计频率，再用小根堆维护频率最高的 `k` 个元素。

2. **[LeetCode #239 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)**：可以使用堆解决，也可以进一步学习更优的单调队列解法。

3. **[LeetCode #378 有序矩阵中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/)**：练习利用堆合并多个有序序列。

### 综合应用

1. **[LeetCode #23 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)**
   
   - **技术结合**：链表 + 小根堆。
   - **核心逻辑**：先将每条链表的头节点放入堆，每次取出最小节点，再把它的下一个节点放入堆。
   - **复杂度**：设节点总数为 `N`，链表数量为 `k`，时间复杂度为 $O(N\log k)$，空间复杂度为 $O(k)$。

2. **[LeetCode #295 数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/)**
   
   - **技术结合**：大根堆 + 小根堆。
   - **核心逻辑**：大根堆保存较小的一半数据，小根堆保存较大的一半数据，并保持两个堆的大小平衡。

### 学习顺序建议

```text
最小堆基础操作
    ↓
第 K 大 / 第 K 小
    ↓
优先队列与元组排序
    ↓
合并多个有序序列
    ↓
双堆维护中位数
```

堆的核心不是记住 `heapq` 的几个函数，而是识别出“需要动态维护当前最小值或最大值”的问题，并根据题目选择小根堆、大根堆或两个堆。
