# 第4课:二分查找

## 第一部分：核心思想与定义

1. **一句话定义**：在**有序**序列中，通过不断将搜索区间减半来定位目标值的算法。
    
2. **核心思想**：**排除法**。就像在字典里查单词，先翻到中间，发现目标在后半部分，就直接扔掉前半部分。
    
3. **关键特征**：
    
    - **前提条件**：数据必须具备**单调性**（通常是有序数组）。
        
    - **效率极高**：时间复杂度为 $O(\log n)$。
        
    - **折半缩减**：每次迭代都能排除掉一半的搜索空间。
        
4. **视觉化表示**：
    
    Plaintext
    
    ```
    Target: 7
    [ 1,  3,  5,  7,  9, 11 ]
      ^     ^           ^
     left  mid        right  (mid < target, 移动 left 到 mid + 1)
    
                [ 7,  9, 11 ]
                  ^   ^   ^
                left mid right (mid == target, 找到！)
    ```

## 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - 关键词：`有序数组`、`旋转有序数组`、`查找目标值`。
        
    - 隐含信号：寻找满足条件的`最小/最大值`、搜索空间巨大但答案有单调性。
        
2. **适用场景**：
    
    - **最佳**：在静态有序数组中查找特定元素。
        
    - **不适用**：链表（无法 $O(1)$ 索引）、无序数据、数据频繁变动。

## 第三部分：标准化解法模板

### 1. 基础模板：查找精确值

```python
def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    while left <= right: # 闭区间 [left, right]
        mid = left + (right - left) // 2 # 防止溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 2. 常见变体：寻找左边界/右边界

- **左边界**（找第一个 $\ge$ target 的数）：`right = mid - 1` 后继续向左收缩。
    
- **旋转数组**：在 `nums[mid]` 与 `nums[left]` 比较判断哪一段是有序的。
    

### 3. 边界条件与陷阱

- **死循环**：确保 `left` 或 `right` 在每次循环都能越过 `mid`（即 `+1` 或 `-1`）。
    
- **中点溢出**：使用 `left + (right - left) // 2` 而非 `(left + right) // 2`。
