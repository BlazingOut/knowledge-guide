# 第5课:链表

## 第一部分：核心思想与定义

1. **一句话定义**：
    
    链表是一种物理存储单元上非连续、非顺序的存储结构，由一系列**节点（Node）**组成，每个节点通过指针指向下一个节点。
    
2. **核心思想**：
    
    链表就像一列**“寻宝火车”**。每个车厢（节点）存放着财宝（数据），并且车厢里还有一张纸条（指针），上面写着下一节车厢所在的精确位置。你必须从第一节车厢开始，按纸条顺序才能找到整列火车的物资。
    
3. **关键特征**：
    
    - **动态扩展**：不需要预先分配固定大小的空间。
        
    - **高效插入/删除**：只需修改指针指向，无需搬移数据（复杂度 $O(1)$）。
        
    - **低效随机访问**：无法像数组一样通过索引直接定位，必须从头遍历（复杂度 $O(n)$）。
        
    - **内存离散**：节点可以分布在内存的任何角落。
        
4. **视觉化表示**：
    
    Plaintext
    
    ```
    [ Data | Next ] --> [ Data | Next ] --> [ Data | Next ] --> NULL
       (Head)             (Node 1)           (Tail)
    ```

## 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - **关键词**：反转、环、合并有序列表、倒数第 K 个、公共节点。
        
    - **模式**：数据量频繁变动；不需要按索引查询，但需要频繁在中间插入或删除。
        
2. **适用场景**：
    
    - **最佳使用**：实现栈和队列、哈希表的拉链法、LRU 缓存淘汰算法。
        
    - **不适用**：需要频繁随机访问数据（如二分查找）。
        
3. **与其他方法的关系**：
    
    | 特征 | 数组 (Array) | 链表 (Linked List) |
    
    | :--- | :--- | :--- |
    
    | **读取 (Access)** | $O(1)$ | $O(n)$ |
    
    | **插入/删除 (Insert/Delete)** | $O(n)$ (需移动元素) | $O(1)$ (已知位置时) |
    
    | **空间连续性** | 必须连续 | 离散存储 |

## 第三部分：标准化解法模板

### 1. 基础模板：链表遍历与构造

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def traverse(head):
    curr = head
    while curr:
        # 处理逻辑
        print(curr.val)
        curr = curr.next
```
next 设定为None

### 2. 核心技巧：哨兵节点 (Dummy Node)

**处理头节点可能变化的情况（如删除节点、合并链表）时的必杀技。**

```python
def process_list(head):
    dummy = ListNode(0) # 创建哨兵
    dummy.next = head
    prev = dummy
    curr = head
    
    while curr:
        if some_condition:
            prev.next = curr.next # 删除或修改操作
        else:
            prev = curr
        curr = curr.next
    return dummy.next # 返回真实的头节点
```

### 3. 边界条件与陷阱

- **空链表**：`if not head: return None`
    
- **单节点链表**：`if not head.next: ...`
    
- **环路陷阱**：在修改指针前，一定要先存下 `next` 节点，否则会丢失后续路径。
    
- **断链风险**：删除节点 A 时，确保 A 的前驱节点指向 A 的后继节点。

## 第四部分：精选题目与学习路径

### **核心母题（1-2题）**

#### 1. [LeetCode #206：反转链表](https://leetcode.cn/problems/reverse-linked-list/)

- **为什么选此题**：这是所有链表操作的元技能，考察对指针交替赋值的理解。
    
- **解题步骤**：
    
    1. 初始化 `prev = None`, `curr = head`。
        
    2. 遍历过程中，暂存 `next_node = curr.next`。
        
    3. 反转指向：`curr.next = prev`。
        
    4. 移动指针：`prev = curr`, `curr = next_node`。
        
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
    

#### 2. [LeetCode #141：环形链表](https://leetcode.cn/problems/linked-list-cycle/)

- **为什么选此题**：引入**快慢指针（Fast & Slow Pointers）**。
    
- **解题步骤**：
    
    1. 快指针走两步，慢指针走一步。
        
    2. 若相遇，必有环。
        
    3. 若快指针走到 NULL，无环。
        
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
    

### **变式进阶（2-3题）**

1. **[LeetCode #21：合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)**（难度：Easy）
    
    - _侧重_：掌握哨兵节点的使用和多指针同步推进。
        
2. **[LeetCode #19：删除链表的倒数第 N 个节点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)**（难度：Medium）
    
    - _侧重_：快慢指针的间距应用（快指针先走 N 步）。
        
3. **[LeetCode #92：反转链表 II（局部反转）](https://leetcode.cn/problems/reverse-linked-list-ii/)**（难度：Medium）
    
    - _侧重_：复杂的指针重连逻辑，极易出错，是面试高频题。
        

### **综合应用（1题）**

1. **[LeetCode #146：LRU 缓存](https://leetcode.cn/problems/lru-cache/)**
    
    - **技术结合**：**双向链表 + 哈希表**。
        
    - **核心逻辑**：哈希表提供 $O(1)$ 查找，双向链表提供 $O(1)$ 的节点移动（删除和置顶）。这是大厂面试中最经典的链表综合设计题。
