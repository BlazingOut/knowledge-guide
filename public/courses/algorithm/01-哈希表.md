# 第1课:哈希表

## 第一部分：核心思想与定义

1. **一句话定义**：一种通过**键（Key）**直接访问**值（Value）**的数据结构，通过映射函数将目标元素转化为数组下标。
    
2. **核心思想**：
    
    - **类比**：就像新华字典的**索引页**。你不需要从第一页翻到最后一页（$O(N)$），而是根据拼音直接跳到对应的页码（$O(1)$）。
        
3. **关键特征**：
    
    - **查找效率极高**：理想情况下，插入、删除、查找均为 $O(1)$。
        
    - **空间换时间**：需要额外的内存来存储键值映射。
        
    - **哈希冲突（Collision）**：不同的 Key 经过哈希运算可能得到相同的下标。

## 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - **关键词**：出现频率、是否存在、第一个重复、去重、两数之和（无序数组）。
        
    - **常见问题模式**：
        
        - “判断元素是否出现过”
        - “统计每个字符出现的次数”            
        - “寻找数组中唯一/重复的数字”
            
2. **适用场景**：
    
    - **最佳使用**：需要快速判断一个元素是否在集合中，或需要建立一对一映射。
        
    - **不适用**：数据规模极小（直接遍历更快）；或者需要维护数据的**有序性**（此时应考虑平衡二叉树/有序映射）。
## 第三部分：标准化解法模板（Python）

Python 中的哈希表有两种主要实现：`set`（集合，只有键）和 `dict`（字典，键值对）。

### 1. 频率统计模板（Counter）

```python
# 统计字符/数字出现次数
def frequency_count(nums):
    lookup = {} # 或者使用 collections.defaultdict(int)
    for x in nums:
        lookup[x] = lookup.get(x, 0) + 1
    return lookup
```

### 2. “是否存在”查询模板（查找两数之和）
```python
def check_exists(nums, target):
    seen = set()
    for x in nums:
        complement = target - x
        if complement in seen:
            return True
        seen.add(x)
    return False
```

### ### 3. 边界条件与陷阱

- **哈希冲突**：Python 内部已处理，但需注意 Key 必须是**可哈希的（Immutable）**，比如 List 不能做字典的 Key，Tuple 可以。
    
- **内存开销**：当数据量达到千万级时，要注意 Python 字典的内存占用


- **`dict` 的查找**：`if diff in prev_map` 在底层是 $O(1)$ 的，这和 Python 的 `list` 查找 `if diff in nums` ($O(N)$) 有本质区别。
    
- **`enumerate`**：这是 Python 处理下标最优雅的方式，相当于 C++ 的 `for(int i=0; i<n; i++)`。

# 集合


要实现 $O(N)$，我们必须利用哈希表 $O(1)$ 的查找能力。
集合`set()`的查找也使用的是哈希表的方式，它的查找相当于是O(1)的。

### 题目说明（最长连续子序列）

给定一个未排序的整数数组，找出其中最长的连续数字序列的长度。序列中的数字不要求在原数组中相邻。

例如：`[100, 4, 200, 1, 3, 2]` 的最长连续序列是 `[1, 2, 3, 4]`，答案为 `4`。

### 使用集合的思路

将所有数字放入集合后，可以用 `O(1)` 的平均时间判断某个数字是否存在。对于每个数字，只有当它的前一个数字不存在时，才把它当作连续序列的起点，再向后查找 `value + 1`、`value + 2`……。这样既能快速查找，又能避免从每个数字重复开始统计。

- **问题特征信号**：
    
    - 关键词：**连续**、**无序数组**、**$O(N)$ 时间复杂度**。
        
    - 要求在一个乱序的集合里找一段数值上连续的区间。
        
- **适用场景**：
    
    - **最佳使用**：不关心元素原始下标，只关心数值连续性。
        
    - **不适用**：要求 $O(1)$ 额外空间（本法需要 $O(N)$ 空间存哈希表）。



```python
def longestConsecutive(nums: list[int]) -> int:
    # 1. 将所有数字放入 set 中，实现 O(1) 查找并去重
    num_set = set(nums)
    longest_streak = 0
    
    # 2. 遍历集合中的每一个数
    for num in num_set:
        # 3. 核心逻辑：判断当前数是否为一个序列的“起点”
        # 只有当 num - 1 不在集合里，num 才是起点
        if (num - 1) not in num_set:
            current_num = num
            current_streak = 1
            
            # 4. 从起点开始，不断查找下一个连续的数
            while (current_num + 1) in num_set:
                current_num += 1
                current_streak += 1
            
            # 5. 更新全局最长长度
            longest_streak = max(longest_streak, current_streak)
            
    return longest_streak
```
