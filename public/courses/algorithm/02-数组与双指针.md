# 第2课:数组与双指针

## 第一部分：核心思想与定义

1. **一句话定义**：通过维护两个（或多个）下标索引，在单次或少量遍历中完成对数组的检索、排序或区间计算。
    
2. **核心思想**：利用数组的**有序性**或**空间结构**，通过指针的移动逻辑减少不必要的重复计算（通常将 $O(N^2)$ 降低到 $O(N)$）。
    
    - **比喻**：就像两个人在跑道上跑步。要么一快一慢（快慢指针），要么从两头向中间靠拢（左右指针），直到相遇。
        
3. **关键特征**：
    
    - 依赖下标访问（Index access）。
        
    - 通过特定的移动条件（Conditional movement）缩小搜索空间。
        
    - 通常不需要额外的空间开销（$O(1)$ 空间复杂度）。

## 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - **关键词**：<mark>有序数组</mark>、寻找两数之和、翻转、去重、子数组/子串、循环检测。
        
    - **常见模式**：
        
        - “在排序数组中寻找...”
            
        - “原地（In-place）修改数组...”
            
        - “寻找最长/最短的连续子区间...”
            
2. **适用场景**：
    
    - **最佳使用**：数组已排序，或者需要原地处理数据。
        
    - **不适用**：数组无序且无法排序（此时哈希表可能更优），或者数据结构不支持随机访问（如某些链表变体）。
        
3. **与其他方法的关系**：
    
    - **vs 哈希表**：哈希表用空间换时间（$O(N)$ 空间），双指针通常空间为 $O(1)$。若数组有序，首选双指针。
        
    - **vs 二分查找**：二分查找是每次砍掉一半搜索空间，双指针是线性移动。


## 第三部分：标准化解法模板（Python）

### 1. 左右指针（常用于有序数组寻找目标值）

```python
def left_right_pointers(nums: list[int], target: int):
    left, right = 0, len(nums) - 1
    while left < right:
        current_sum = nums[left] + nums[right]
        if current_sum == target:
            return [left, right]
        elif current_sum < target:
            left += 1  # 需要更大的值
        else:
            right -= 1 # 需要更小的值
    return [-1, -1]
```
**核心思想**：通过左右指针的移动，逐步缩小搜索范围，直到找到目标值或搜索空间耗尽。



### 2. 快慢指针（常用于原地修改、去重）
```python
def fast_slow_pointers(nums: list[int]):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0: # 某种筛选条件
            nums[slow], nums[fast] = nums[fast], nums[slow] # Python特有的交换写法
            slow += 1
            
```
> [!Note]
> 快慢指针的这个条件 的反义，就是fast与slow开始分歧的条件。
> 
> 这里当`nums[fast] == 0` 的时候，也就是slow停止，而fast还在继续的时候。
> 也就是说slow--fast 的这个区间 就是 nums == 0 的区间。
> 此时 slow 指向的就是 第一个 == 0 的位置，fast指向的是第一个 != 0 的位置。（当状态发生变化的时候）

### 3. 边界条件与陷阱

- **指针越界**：`while left < right` 还是 `left <= right`？（取决于是否需要处理重合点）。
    
- **空数组/单元素**：务必先判断 `if not nums: return`。
    
- **整型溢出**：虽然 Python 3 自动处理大整数，但在 C++ 转 Python 时要习惯思考 `mid = left + (right - left) // 2`（Python 中 `//` 是地板除）。


## 快慢指针

**快慢指针的目标**：通过覆盖（Overwriting）而不是删除，在 $O(N)$ 时间内完成任务。

- **慢指针 (`slow`)**：代表“确定==被保留下来的元素==”的末尾边界。
    
- **快指针 (`fast`)**：代表“正在扫描的当前元素”。
```python

def removeDuplicates(nums: list[int]) -> int:
    if not nums:
        return 0
    
    # 1. 初始化
    # 第一个元素（nums[0]）肯定是不重复的，所以 slow 从 0 开始
    slow = 0 
    
    # 2. 快指针遍历整个数组
    # 从 1 开始遍历，因为我们要拿 nums[fast] 和 nums[slow] 比较
    for fast in range(1, len(nums)):
        
        # 3. 核心判断条件
        # 如果快指针指向的值 和 慢指针指向的值 不同
        # 说明我们找到了一个新的、不重复的元素
        if nums[fast] != nums[slow]:
            # 慢指针前进一位，为新元素腾出位置
            slow += 1
            # 将新元素覆盖到慢指针当前的位置
            nums[slow] = nums[fast]
            
    # 4. 返回长度
    # 因为 slow 是下标，长度需要下标 + 1
    return slow + 1

```

## 列题
有序数组两数之和
给定有序数组：

```python
nums = [1, 2, 4, 6, 8, 10]
target = 10
```
寻找两个数，使它们的和等于 10。
```python
def two_sum_sorted(nums: list[int], target: int) -> list[int]:
    left, right = 0, len(nums) - 1

    while left < right:
        current_sum = nums[left] + nums[right]

        if current_sum == target:
            return [left, right]
        elif current_sum < target:
            left += 1
        else:
            right -= 1

    return [-1, -1]
```
