
# 动态规划 (Dynamic Programming)

### 第一部分：核心思想与定义

1. **一句话定义**：将一个复杂问题分解成若干个**重叠**的子问题，通过存储子问题的解（记忆化）来避免重复计算，最终推导出全局最优解。
    
2. **核心思想**：**“以此类推”**。就像爬楼梯，如果你知道爬到第 8 阶和第 9 阶的方法数，那么爬到第 10 阶的方法数就是两者的和。
    
3. **关键特征**：
    
    - **重叠子问题**：同一个子问题会被多次计算。
        
    - **最优子结构**：大问题的最优解包含子问题的最优解。
        
    - **无后效性**：一旦某个状态确定，它之后的决策不会影响之前的状态。
        
4. **视觉化表示**（以斐波那契数列为例）：
    

Plaintext

```
           f(5)
         /      \
      f(4)      f(3)
     /   \      /   \
  f(3)   f(2) f(2)  f(1)  <-- f(3) 和 f(2) 被重复计算了！
DP 通过一个数组 dp = [0, 1, 1, 2, 3, 5] 直接记录结果。
```

### 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - **关键词**：最少、最多、最大、最小、有多少种方式、是否可能。
        
    - **核心特征**：求一个最优值，且这个值取决于前面的决策。
        
2. **适用场景**：
    
    - **最佳使用**：背包问题、路径规划（如矩阵最小路径和）、序列比对（如最长公共子序列）。
        
    - **不适用**：求具体的所有路径（通常用 DFS）、数据之间没有递推关系。
        
3. **与其他方法的关系**：
    
    |**维度**|**贪心算法**|**动态规划**|
    |---|---|---|
    |**决策**|每一步选局部最优|综合考虑所有子问题结果|
    |**回溯**|不可回退|隐含了对所有路径的“尝试”|

### 第三部分：标准化解法模板（动规五部曲）

无论题目怎么变，按这五步走逻辑就不会乱：

1. **确定 dp 数组及下标的含义**：`dp[i]` 代表什么？（如：爬到第 $i$ 层的方法数）
    
2. **确定状态转移方程**：`dp[i] = dp[i-1] + dp[i-2]`（这是 DP 的灵魂）。
    
3. **dp 数组如何初始化**：`dp[0] = 0, dp[1] = 1`（初始值错了，后面全错）。
    
4. **确定遍历顺序**：是从前向后，还是从后向前？
    
5. **举例推导 dp 数组**：手动模拟前几个数据，确保逻辑正确。

### 1. 一维 DP 模板

适用于当前状态只依赖于前面有限状态的问题，例如爬楼梯、打家劫舍和零钱兑换。

```python
def solve(nums):
    # 步骤 1：dp[i] 的含义由题目决定。
    # 这里假设 dp[i] 表示处理到位置 i 时的最优结果。
    dp = [0] * len(nums)

    # 步骤 2：根据题意初始化边界状态。
    dp[0] = initial_value

    # 步骤 3：按状态依赖关系遍历。
    for i in range(1, len(nums)):
        # 步骤 4：由已经求出的状态转移到当前状态。
        dp[i] = transition(dp, i)

    # 步骤 5：返回题目要求的最终状态。
    return dp[-1]
```

### 2. 二维 DP 模板

适用于状态由两个维度决定的问题，例如网格路径、两个字符串的匹配和编辑距离。

```python
def solve(rows, cols):
    # 步骤 1：dp[row][col] 表示两个维度确定后的子问题答案。
    dp = [[0] * cols for _ in range(rows)]

    # 步骤 2：初始化第一行、第一列或其他边界状态。
    initialize(dp)

    # 步骤 3：按依赖方向遍历每个状态。
    for row in range(1, rows):
        for col in range(1, cols):
            # 步骤 4：由相邻子问题推导当前状态。
            dp[row][col] = transition(dp, row, col)

    # 步骤 5：返回目标位置的答案。
    return dp[rows - 1][cols - 1]
```

### 3. 0-1 背包模板：每件物品只能选一次

0-1 背包的关键不是代码公式，而是**容量必须逆序遍历**。这样计算 `dp[capacity]` 时，读取到的 `dp[capacity - weight]` 仍然是“没有使用当前物品”时的旧状态，因此同一件物品不会被重复选择。

```python
def zero_one_knapsack(weights, values, capacity):
    # dp[c]：容量不超过 c 时，可以获得的最大价值。
    dp = [0] * (capacity + 1)

    # 步骤 1：逐个考虑物品。
    for index in range(len(weights)):
        weight = weights[index]
        value = values[index]

        # 步骤 2：容量逆序遍历，保证当前物品最多只使用一次。
        for current_capacity in range(capacity, weight - 1, -1):
            # 步骤 3：比较“不选当前物品”和“选当前物品”。
            dp[current_capacity] = max(
                dp[current_capacity],
                dp[current_capacity - weight] + value,
            )

    return dp[capacity]
```

### 4. 完全背包模板：每件物品可以重复选

完全背包的容量必须**正序遍历**。计算 `dp[capacity]` 时，可以使用本轮已经更新过的 `dp[capacity - weight]`，因此当前物品能够被重复选取。

```python
def complete_knapsack(weights, values, capacity):
    # dp[c]：容量不超过 c 时，可以获得的最大价值。
    dp = [0] * (capacity + 1)

    # 步骤 1：逐个考虑物品。
    for index in range(len(weights)):
        weight = weights[index]
        value = values[index]

        # 步骤 2：容量正序遍历，允许当前物品重复使用。
        for current_capacity in range(weight, capacity + 1):
            # 步骤 3：更新当前容量的最优结果。
            dp[current_capacity] = max(
                dp[current_capacity],
                dp[current_capacity - weight] + value,
            )

    return dp[capacity]
```

### 5. 背包初始化和遍历方向

| 问题类型 | `dp[c]` 常见含义 | 初始化 | 容量遍历方向 |
| :--- | :--- | :--- | :--- |
| 0-1 背包求最大价值 | 容量不超过 `c` 的最大价值 | 全部为 `0` | 逆序 |
| 完全背包求最大价值 | 容量不超过 `c` 的最大价值 | 全部为 `0` | 正序 |
| 恰好装满求最大价值 | 恰好容量为 `c` 的最大价值 | `dp[0] = 0`，其余为负无穷 | 由物品数量决定 |
| 凑出金额的最少元素数 | 凑出金额 `c` 的最少数量 | `dp[0] = 0`，其余为正无穷 | 通常正序 |

“组合数”和“排列数”也由循环顺序决定：

- **组合**：先遍历物品，再遍历容量。例如 `1 + 2` 与 `2 + 1` 被视为同一种选法；
- **排列**：先遍历容量，再遍历物品。例如 `1 + 2` 与 `2 + 1` 被视为不同顺序。

### 第四部分：精选题目与学习路径

**核心母题（2题）**

1. **[LeetCode #70 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)**
    
    - **为什么选此题**：最基础的一维 DP，用来练习状态定义、初始化和从前向后的状态转移。
        
    - **解题思路**：`dp[i]` 表示到达第 `i` 阶的方法数，`dp[i] = dp[i - 1] + dp[i - 2]`。
        
2. **[LeetCode #322 零钱兑换](https://leetcode.cn/problems/coin-change/)**
    
    - **为什么选此题**：它是“完全背包”的变体，也是最能体现“状态转移”思想的题目。
        
    - **解题思路**：
        
        - `dp[i]`：凑齐金额 `i` 所需的最少硬币数。
            
        - 方程：`dp[i] = min(dp[i], dp[i - coin] + 1)`。
            
    - **代码核心**：
        

```python

def coinChange(coins, amount):
    # dp[value]：凑出金额 value 所需的最少硬币数。
    # 初始设为无穷大，表示该金额暂时无法凑出。
    dp = [float('inf')] * (amount + 1)

    # 凑出金额 0 不需要硬币，是状态转移的起点。
    dp[0] = 0

    # 先遍历硬币，再正序遍历金额：每种硬币可以重复选择。
    for coin in coins:
        for value in range(coin, amount + 1):
            # 选择当前硬币后，最少硬币数比凑出 value - coin 多一个。
            dp[value] = min(dp[value], dp[value - coin] + 1)

    # 无穷大表示无法凑出目标金额。
    return dp[amount] if dp[amount] != float('inf') else -1
```
