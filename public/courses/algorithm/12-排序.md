# 第12课:排序



## 第一部分：核心思想与定义

1. **一句话定义**：通过一趟排序将待排记录分隔成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，则可分别对这两部分记录继续进行排序。
    
2. **核心思想**：**“分而治之 + 找基准”**。想象你在排队领盒饭，你随便找一个人（基准），让比他矮的站左边，比他高的站右边，然后这两群人再分别如法炮制，直到最后全队有序。
    
3. **关键特征**：
    
    - **分治法**：将大问题转化为子问题。
        
    - **原地排序 (In-place)**：除了递归调用栈，不需要额外的存储空间。
        
    - **不稳定性**：相等元素的相对位置可能会改变。
        
4. **视觉化表示**：
    
    Plaintext
    
    ```
    [5, 2, 9, 3, 8]  基准选 5
     /     |     \
    [2, 3] (5) [9, 8]  (小于5的在左，大于5的在右)
     / \        / \
    (2) (3)    (8) (9)
    最终拼接: [2, 3, 5, 8, 9]
    ```

## 第二部分：适用场景与问题识别

1. **问题特征信号**：
    
    - **关键词**：排序、中位数、第 K 大的数（快速选择算法）。
        
    - **模式**：需要在平均 $O(N \log N)$ 时间内完成排序，且对空间要求较高。
        
2. **适用场景**：
    
    - **最佳使用情况**：数据分布均匀，内存空间有限。
        
    - **不适用情况**：数据已经近乎有序（会导致 $O(N^2)$ 的最坏情况）；对排序稳定性有严格要求。
        
3. **与其他方法的关系**：
    
    |**特性**|**快速排序**|**归并排序**|
    |---|---|---|
    |**核心思想**|分治 (由上而下：先分区再递归)|分治 (由下而上：先递归再合并)|
    |**空间复杂度**|$O(\log N)$ (递归栈)|$O(N)$ (辅助数组)|
    |**稳定性**|不稳定|稳定|
    |**选择建议**|追求速度和空间效率首选|追求稳定或处理链表时首选|

## 第三部分：标准化解法模板（Python）

### 1. 基础模板：双指针分区法

```python
def quick_sort(nums, left, right):
    if left >= right: return
    
    # 分区操作，返回基准值的最终位置
    pivot_idx = partition(nums, left, right)
    
    # 递归排序左右两部分
    quick_sort(nums, left, pivot_idx - 1)
    quick_sort(nums, pivot_idx + 1, right)

def partition(nums, left, right):
    pivot = nums[left]  # 选取第一个元素作为基准
    low = left
    high = right
    
    while low < high:
        while low < high and nums[high] >= pivot: 
            high -= 1
            nums[low] = nums[high]
        while low < high and nums[low] <= pivot: 
            low += 1
            nums[high] = nums[low]
        
    nums[low] = pivot
    return low
```

### 2. 常见变体：三行 Pythonic 式（用于快速理解，面试不建议）

Python

```python
def quick_sort_simple(nums):
    if len(nums) <= 1: return nums
    pivot = nums[len(nums) // 2]
    left = [x for x in nums if x < pivot]
    middle = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]
    return quick_sort_simple(left) + middle + quick_sort_simple(right)
```

### 3. 边界条件与陷阱

- **最坏情况预防**：如果数组已经有序，固定选第一个数做基准会退化到 $O(N^2)$。**对策**：随机选取基准（Random Pivot）。
    
- **大量重复元素**：可能导致分区不平衡。**对策**：采用三路快排（分成小于、等于、大于三部分）。

## 第四部分：精选题目与学习路径

**核心母题（1题）**

1. **LeetCode #912. 排序数组**
    
    - **为什么选此题**：最纯粹的测试，能检验你的快排模板是否通过了边界测试（尤其是大量重复元素的大规模测试）。
        
    - **解题步骤**：实现 `partition` -> 递归处理左右区间。
        
    - **时间复杂度**：平均 $O(N \log N)$，最坏 $O(N^2)$。
        

**变式进阶（2题）**

1. **LeetCode #215. 数组中的第K个最大元素**
    
    - **侧重点**：**快速选择 (Quick Select)**。这是快排最重要的变体。你不需要对两边都递归，只需要递归包含第 K 个元素的那一边。时间复杂度优化至 $O(N)$。
        
2. **LeetCode #75. 颜色分类 (荷兰国旗问题)**
    
    - **侧重点**：**三路快排**的思想。在一个数组中处理三种不同的值（0, 1, 2），是快排分区逻辑的极致应用。
        

**综合应用（1题）**

1. **LeetCode #973. 最接近原点的 K 个点**
    
    - **侧重点**：将快排/快速选择思想应用于自定义权重（距离）的比较。
