# 栈与队列


## 第一部分：核心思想与定义

### 1. 一句话定义

栈（Stack）是**后进先出（LIFO）**的线性表，队列（Queue）是**先进先出（FIFO）**的线性表。

### 2. 核心思想

- **栈 (Stack)**：像堆叠盘子，最后放上去的必须最先拿走。
    
- **队列 (Queue)**：像排队买票，先来的人先买到票离开。
    
- **双端队列 (Deque)**：像一条两端都通的管子，两头都能进出。
    

### 3. 关键特征

- **栈**：仅在一端（栈顶）进行操作。
    
- **队列**：一端进（队尾），另一端出（队首）。
    
- **性能要求**：基础的入队/出队、入栈/出栈操作都必须是 $O(1)$ 时间复杂度。
    

### 4. 视觉化表示

Plaintext

```
栈 (Stack - LIFO)            队列 (Queue - FIFO)
|   7   | <- 栈顶 (Top)      出队 <- [ 1, 2, 3, 4 ] <- 入队
|   8   |                     (Head)         (Tail)
|   9   |
+-------+ 栈底
```

## 第二部分：适用场景与问题识别

### 1. 问题特征信号

- **栈**：递归转迭代、括号匹配、单调栈（找下一个更大元素）、路径回溯。
    
- **队列**：层级遍历（BFS）、滑动窗口基础实现、任务缓冲池。
    

### 2. 适用场景

|**场景**|**推荐工具**|**原因**|
|---|---|---|
|**栈操作**|`list`|结尾追加和弹出 `append/pop` 是 $O(1)$。|
|**普通队列**|`collections.deque`|`list.pop(0)` 是 $O(n)$，`deque.popleft()` 是 $O(1)$。|
|**优先队列**|`heapq`|需要按优先级（大小）而非顺序出队。|

### 3. 与其他方法的关系

- **List vs Deque**：不要用 `list` 模拟队列，因为在列表头部删除元素会导致后续所有元素位移，效率极低。

## 第三部分：标准化解法模板

### 1. 基础模板：栈 (Stack)

Python 的内置 `list` 就是天然的栈。

```python
stack = []
stack.append(1)  # 入栈 (Push)
stack.append(2)
top = stack[-1]  # 查看栈顶 (Peek)
val = stack.pop() # 出栈 (Pop) -> 2
is_empty = not stack # 判空
```

### 2. 常见变体：队列 (Queue / Deque)

必须使用 `collections.deque` 以保证高性能。


```python
from collections import deque

# 模拟队列 (FIFO)
queue = deque()
queue.append(1)      # 入队
queue.append(2)
val = queue.popleft() # 出队 -> 1 (注意是 popleft)

# 模拟双端队列 (Deque)
dq = deque([2, 3])
dq.append(4)         # 右侧入
dq.appendleft(1)     # 左侧入 [1, 2, 3, 4]
dq.pop()             # 右侧出
dq.popleft()         # 左侧出
```

### 3. 边界条件与陷阱

- **空操作报错**：在调用 `pop()` 或 `popleft()` 之前，**必须**先检查 `if stack:` 或 `if queue:`，否则会抛出 `IndexError`。
    
- **线程安全**：`collections.deque` 是线程安全的，但在算法刷题中通常不涉及并发，主要关注其 $O(1)$ 的两端操作性能。

## 第四部分：精选题目与学习路径

### 核心母题

1. **[LeetCode #20 有效的括号](https://leetcode.cn/problems/valid-parentheses/) (栈的入门)**
    
    - **为什么选此题**：展示了栈如何处理“最近相关性”问题。
        
    - **解题步骤**：遇左括号入栈，遇右括号弹出栈顶匹配，最后检查栈是否为空。
        
    - **复杂度**：时间 $O(n)$，空间 $O(n)$。
        
2. **[LeetCode #102 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/) (队列的入门)**
    
    - **为什么选此题**：BFS 的标准模板，必须依赖队列实现。
        
    - **解题步骤**：初始节点入队 -> 循环判空 -> 记录当前层长度 -> 逐个出队并将其子节点入队。
        

### 变式进阶

- **[LeetCode #232 用栈实现队列](https://leetcode.cn/problems/implement-queue-using-stacks/)**：考察对两个线性结构特性的深度理解（双栈转换法）。
    
- **[LeetCode #155 最小栈](https://leetcode.cn/problems/min-stack/)**：在 $O(1)$ 时间获取最小值（辅助栈模式）。
    
- **[LeetCode #239 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)**：双端队列（Deque）的高级应用——单调队列。
    

### 综合应用

- **[LeetCode #739 每日温度](https://leetcode.cn/problems/daily-temperatures/)**：经典的**单调栈**应用，将栈的后进先出特性与数值的大小比较结合。
