# 第9课:二叉树
## 第一部分：核心思想与定义

### 1. 一句话定义

二叉树是每个节点最多有两个子节点（左子树和右子树）的递归性层次数据结构。

### 2. 核心思想

**递归（Recursion）的本质**。二叉树的定义本身就是递归的：一个二叉树要么为空，要么由一个根节点加上两棵子二叉树组成。这种结构决定了绝大多数二叉树问题都可以通过“处理当前节点 + 递归处理子节点”来解决。

### 3. 关键特征

- **度限制**：每个节点的度 $d \le 2$。
    
- **有序性**：左子树和右子树的顺序不可颠倒。
    
- **层次性**：深度为 $h$ 的二叉树最多有 $2^h - 1$ 个节点。
    
- **唯一性**：通过“中序+前序”或“中序+后序”可以唯一确定一棵二叉树（仅靠前序+后序不行）。
    

### 4. 视觉化表示（以 DFS 遍历为例）

Plaintext

```
      A (根)
     /   \
    B     C
   / \     \
  D   E     F

前序 (根-左-右): A -> B -> D -> E -> C -> F
中序 (左-根-右): D -> B -> E -> A -> C -> F
后序 (左-右-根): D -> E -> B -> F -> C -> A
层序 (按层扫描): A -> B -> C -> D -> E -> F
```

## 第二部分：适用场景与问题识别

### 1. 问题特征信号

- **关键词列表**：路径总和、最大深度、镜像翻转、最近公共祖先、层序输出、左右子树对称。
    
- **常见问题模式**：
    
    - “求树的属性”（深度、节点数）。
        
    - “路径搜索”（满足条件的路径）。
        
    - “结构重构”（根据序列重建树）。
        

### 2. 适用场景

- **最佳使用情况**：需要层级组织数据、需要 $O(\log N)$ 搜索效率（BST形式）、分治法求解。
    
- **不适用的情况**：数据元素之间是多对多关系（应选图）、频繁在中间位置插入/删除且无需排序（应选链表）。
    

### 3. 与其他方法的关系

|**维度**|**DFS（深度优先）**|**BFS（广度优先）**|
|---|---|---|
|**底层工具**|递归 / 栈|队列|
|**适用场景**|找路径、找公共祖先、遍历整棵树|找最短路径、层序输出、求最小深度|
|**空间复杂度**|最坏 $O(H)$（树高）|最坏 $O(W)$（最大宽度）|

## 第三部分：标准化解法模板

### 1. 基础模板：DFS 递归（以中序遍历为例）

Python

```
def dfs(root):
    if not root:
        return
    
    # 前序位置：刚进入节点
    dfs(root.left)
    # 中序位置：左子树处理完
    print(root.val)
    dfs(root.right)
    # 后序位置：左右子树都处理完
```

### 2. 常见变体：BFS 层序遍历


```python
from collections import deque

def bfs(root):
    if not root: return []
    queue = deque([root])
    res = []
    while queue:
        level_size = len(queue) # 当前层的节点数
        current_level = []
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        res.append(current_level)
    return res
```

### 3. 边界条件与陷阱

- **空树处理**：`if not root: return` 是几乎所有递归的第一行。
    
- **叶子节点判断**：`if not root.left and not root.right`。
    
- **递归深度**：Python 默认限制 1000 层，极端偏斜树可能需要 `sys.setrecursionlimit`。

## 第四部分：精选题目与学习路径

### **核心母题（2题）**

1. **[LeetCode #104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)**
    
    - **为什么选此题**：理解递归回溯的核心。每个节点的深度等于 `max(左深度, 右深度) + 1`。
        
    - **解题步骤**：1. 终止条件（空树深度0）；2. 递归求左、右子树深度；3. 取最大值加1返回。
        
    - **复杂度**：$O(N)$，每个节点访问一次。
        
2. **[LeetCode #102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)**
    
    - **为什么选此题**：掌握 BFS 模板的核心。它是解决所有“最短路”或“层级”问题的基础。
        
    - **解题步骤**：使用 `deque` 队列，通过 `len(queue)` 锁定当前层边界。
        
    - **复杂度**：$O(N)$。

    - **侧重点**：后序遍历返回值传递，理解递归的“自底向上”通信。
        

### **综合应用（1题）**

    - **综合点**：结合了“后序遍历”、“全局变量维护”和“路径逻辑判断”。考察你是否能区分“节点最大贡献值”与“包含该节点的完整最大路径”。

## 平衡二叉搜索树

将有序数组转化为二叉搜索树（BST）是考察分治算法（Divide and Conquer）与二叉树结构特性的经典题目（[LeetCode #108](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)）。

这里的核心目标是转化出一棵**高度平衡**的 BST。

---

## 第一部分：核心思想与定义

### 1. 一句话定义

利用有序数组的中间元素作为根节点，递归地将左半部分和右半部分数组分别构建为左右子树。

### 2. 核心思想

- **“平衡”的秘诀**：要让树平衡，左右子树的节点数量必须尽量接近。既然数组是有序的，**数组正中间的数**就是根节点的最佳人选。
    
- **折半查找的比喻**：这个过程就像“折半查找（Binary Search）”的逆过程。折半查找是在树上找数，而本题是根据折半的过程把树“种”出来。
    

### 3. 关键特征

- **中序遍历的逆向工程**：BST 的中序遍历结果就是一个有序数组。本题要求我们通过中序遍历结果反推原树。
    
- **递归构造**：由于每个子树本身也必须是高度平衡的 BST，因此该逻辑具有天然的递归性。
    

### 4. 视觉化表示

Plaintext

```
数组: [-10, -3, 0, 5, 9]
          ^ 中间值 0 成为根

      0
     / \
  [-10, -3] [5, 9]
    ^ 选择 -3 或 -10 作为子根（取决于取整策略）

结果可能为：
      0
     / \
   -3   9
   /   /
 -10  5
```

---

## 第二部分：适用场景与问题识别

### 1. 问题特征信号

- **关键词**：有序数组、转换为 BST、高度平衡。
    
- **隐形条件**：平衡二叉树意味着每个节点的左右子树高度差不超过 1。
    

### 2. 适用场景

- 将静态排序数据转换为支持快速搜索的动态结构。
    
- **不适用**：如果数组无序，必须先排序或使用其他平衡树算法（如 AVL、红黑树插入）。
    

### 3. 与其他方法的关系

| **需求**       | **方法**      | **原因**                 |     |
| ------------ | ----------- | ---------------------- | --- |
| **仅构建 BST**  | 选首个元素做根     | 可能退化成链表                |     |
| **构建平衡 BST** | **选中间元素做根** | **保证左右子节点数量差 $\le 1$** |     |
| **数组转化为二叉树** | 层序遍历填充      | 无法保证 BST 性质（左小右大）      |     |

## 第三部分：标准化解法模板

### 1. 基础模板：递归分治（最常用）

```python
def sortedArrayToBST(nums: List[int]) -> TreeNode:
    def build(left, right):
        # 边界条件：左指针超过右指针，说明子数组为空
        if left > right:
            return None
        
        # 1. 寻找中间索引（防止溢出的写法）
        mid = left + (right - left) // 2
        
        # 2. 创建当前节点
        root = TreeNode(nums[mid])
        
        # 3. 递归构建左右子树
        root.left = build(left, mid - 1)
        root.right = build(mid + 1, right)
        
        return root

    return build(0, len(nums) - 1)
```

### 2. 边界条件与陷阱

- **中间点的选择**：对于偶数个元素，选 `(left + right) // 2` 还是 `(left + right + 1) // 2` 都可以，只是生成的平衡树形态略有不同。
    
- **区间闭合**：通常使用闭区间 `[left, right]`，此时递归终止条件是 `left > right`。

## 第四部分：精选题目与学习路径

**核心母题：[LeetCode #108](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)**

- **为什么选此题**：它是理解 BST 性质和分治思想的完美结合。
    
- **解题步骤**：找中点 -> 建根 -> 递归左边 -> 递归右边。
    
- **复杂度分析**：
    
    - 时间：$O(N)$，每个数组元素都要转换成节点。
        
    - 空间：$O(\log N)$，递归栈深度等于树高。
        

**变式进阶**

1. **[LeetCode #109. 有序链表转换二叉搜索树](https://leetcode.cn/problems/convert-sorted-list-to-binary-search-tree/)** (Medium)
    
    - **挑战点**：链表不能像数组那样 $O(1)$ 找中点。需要用**快慢指针**寻找中点，或者使用**中序遍历构造法**来达到 $O(N)$ 时间。
        
2. **[LeetCode #1382. 将二叉搜索树变平衡](https://leetcode.cn/problems/balance-a-binary-search-tree/)** (Medium)
    
    - **挑战点**：先把不平衡的 BST 中序遍历成有序数组，再套用本题模板。

**导师总结**：

这道题的精髓在于“信任递归”。只要你每次都取中间值，你就保证了“当前”这棵树是平衡的，剩下的交给子递归去完成同样的任务。
