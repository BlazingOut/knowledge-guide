# 递归

## 第一部分：核心思想与定义

### 1. 一句话定义

递归是函数调用自身来解决问题的方法。它把一个大问题拆成规模更小、形式相同的子问题，直到遇到可以直接解决的情况。

### 2. 一个递归函数的三个部分

一个正确的递归函数通常包含三个部分：

1. **终止条件**：什么时候停止继续调用自己；
2. **缩小问题**：下一次调用时，问题规模必须变小；
3. **当前层处理**：使用子问题的结果，得到当前问题的结果。

以阶乘为例：

```text
n! = n × (n - 1)!
0! = 1
```

其中：

- `n == 0` 是终止条件；
- `factorial(n - 1)` 是规模更小的子问题；
- `n * factorial(n - 1)` 是当前层的处理逻辑。

### 3. 递归调用是怎样执行的

调用递归函数时，当前函数不会立刻结束，而是先等待下一层返回结果。

以 `factorial(3)` 为例：

```text
调用阶段：
factorial(3)
    -> 3 * factorial(2)
              -> 2 * factorial(1)
                        -> 1 * factorial(0)

返回阶段：
factorial(0) = 1
factorial(1) = 1 * 1 = 1
factorial(2) = 2 * 1 = 2
factorial(3) = 3 * 2 = 6
```

递归调用阶段不断深入，满足终止条件后再逐层返回。每一层函数的参数、局部变量和返回位置，都会暂时保存在调用栈中。

### 4. 递归与循环

递归和循环都可以处理重复执行的逻辑：

| 对比项 | 递归 | 循环 |
| :--- | :--- | :--- |
| 重复方式 | 函数调用自身 | `for` 或 `while` |
| 状态保存 | 系统调用栈 | 循环变量 |
| 优点 | 代码更接近问题的定义 | 通常更节省额外空间 |
| 风险 | 递归过深可能栈溢出 | 容易写错循环边界 |

例如，计算 `1` 到 `n` 的和既可以写成递归，也可以写成循环。递归不一定比循环更快，它的主要价值是帮助我们表达“一个问题由更小的同类问题组成”。

## 第二部分：适用场景与问题识别

### 1. 问题特征信号

遇到下面的情况，可以考虑递归：

- 当前问题可以自然地写成更小问题的形式；
- 每次处理都会让数据规模变小；
- 题目中的对象具有嵌套结构；
- 题目要求重复处理相同类型的对象，且处理深度不容易提前确定。

当前阶段只关注最简单的递归场景：数字、字符串和线性序列。二叉树、搜索和回溯等内容放到后续课程中学习。

### 2. 常见的简单场景

#### 数字递归

阶乘、累加、幂运算、最大公约数等问题，都可以将当前数字转换成更小的数字。

#### 字符串递归

可以先处理第一个字符，再递归处理剩余字符串；也可以先递归处理剩余部分，再处理当前字符。

#### 线性序列递归

可以使用下标表示当前处理位置，每次递归让下标向后移动，直到越过序列末尾。

### 3. 写递归前先回答四个问题

1. **函数的参数表示什么？**
2. **什么时候停止？**
3. **下一次调用如何让问题变小？**
4. **子问题的结果如何帮助当前层得到答案？**

如果这四个问题没有明确答案，不要急着写递归代码，先用一句话定义函数的含义。

例如：

```python
sum_to_n(n)
```

可以先定义为：“返回从 `1` 加到 `n` 的结果。”有了这个定义，递推关系就是：

```text
sum_to_n(n) = n + sum_to_n(n - 1)
```

### 4. 什么时候不适合使用递归

- 问题规模很大，递归层数可能过深；
- 使用简单循环就能清楚解决；
- 递归代码需要保存大量状态，导致理解和调试困难。

Python 默认递归深度有限，递归层数过深时可能抛出 `RecursionError`。因此，递归应该服务于问题表达，而不是为了使用递归而使用递归。

## 第三部分：标准化解法模板

### 1. 基础模板

```python
def recursion(state):
    # 1. 终止条件
    if is_finished(state):
        return base_answer

    # 2. 处理当前层
    current_result = do_something(state)

    # 3. 进入规模更小的子问题
    next_result = recursion(smaller_state(state))

    # 4. 合并当前层和子问题结果
    return combine(current_result, next_result)
```

实际写题时不一定需要把四步都拆成变量，但思考顺序最好保持一致。

### 2. 模板：计算阶乘

```python
def factorial(n: int) -> int:
    if n == 0:
        return 1

    return n * factorial(n - 1)
```

执行 `factorial(4)` 时，调用会一直从 `4` 减到 `0`，然后按照相反顺序返回结果。

### 3. 模板：计算一到 n 的和

```python
def sum_to_n(n: int) -> int:
    if n == 0:
        return 0

    return n + sum_to_n(n - 1)
```

这里的函数含义是“返回 `1` 到 `n` 的总和”，所以当前层只需要把 `n` 加到 `sum_to_n(n - 1)` 上。

### 4. 模板：使用下标处理序列

```python
def sum_list(nums: list[int], index: int = 0) -> int:
    if index == len(nums):
        return 0

    return nums[index] + sum_list(nums, index + 1)
```

这个模板有两个状态：

- `nums`：要处理的序列；
- `index`：当前处理到的位置。

终止条件是 `index` 到达序列长度，每次递归将 `index` 加一。

### 5. 模板：判断字符串是否为回文串

```python
def is_palindrome(s: str, left: int = 0, right: int | None = None) -> bool:
    if right is None:
        right = len(s) - 1

    if left >= right:
        return True

    if s[left] != s[right]:
        return False

    return is_palindrome(s, left + 1, right - 1)
```

每次比较两端字符，然后让 `left` 向右、`right` 向左，问题规模逐渐缩小。

### 6. 模板：最大公约数

利用欧几里得算法：

```text
gcd(a, b) = gcd(b, a % b)
gcd(a, 0) = a
```

代码如下：

```python
def gcd(a: int, b: int) -> int:
    if b == 0:
        return a

    return gcd(b, a % b)
```

这个例子说明，递归不一定只处理“减一”的问题，只要下一次的问题更接近终止条件即可。

### 7. 边界条件与常见陷阱

- **忘记终止条件**：函数会一直调用自身，最终栈溢出；
- **问题规模没有变小**：下一次调用仍然传入相同参数，会无限递归；
- **终止条件写错**：例如空序列、单个元素等情况没有正确处理；
- **忘记 `return`**：子函数已经算出结果，但当前层没有把结果返回；
- **边界移动方向错误**：处理字符串或数组时，下标没有向终止条件靠近；
- **没有检查输入范围**：例如阶乘函数没有处理负数输入。

写完递归后，建议手动追踪一个最小输入和一个普通输入，检查调用阶段能否停止、返回阶段能否得到正确结果。

## 第四部分：精选题目与学习路径

### 核心母题

1. **[LeetCode #509 斐波那契数](https://leetcode.cn/problems/fibonacci-number/)**

   - **为什么选此题**：练习一个函数调用两个更小规模的同类问题。
   - **递归关系**：`F(n) = F(n - 1) + F(n - 2)`。
   - **重点**：处理 `F(0)` 和 `F(1)` 两个终止条件。

2. **[LeetCode #50 Pow(x, n)](https://leetcode.cn/problems/powx-n/)**

   - **为什么选此题**：练习通过缩小指数解决幂运算问题。
   - **重点**：处理 `n == 0`、负数指数和整数溢出边界。

### 简单练习

1. **[LeetCode #344 反转字符串](https://leetcode.cn/problems/reverse-string/)**：练习交换两端字符，并递归处理更小的区间。
2. **[LeetCode #779 第 K 个语法符号](https://leetcode.cn/problems/k-th-symbol-in-grammar/)**：练习根据上一层结果递归推导当前结果。
